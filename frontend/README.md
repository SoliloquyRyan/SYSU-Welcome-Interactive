# 前端

Vue 3 + Vite 前端。D-022 已将三个入口接到同一套本地服务端权威状态：

- `/welcome`：NFC 个性令牌主入口、姓名+合成学号备用核验、Kelvin 星色锁定并直接入场、星星、节目礼物与弹幕、协同点亮和个人档案。
- `/screen`：三场景匿名聚合、中场抽奖、公开弹幕、终章和断线安全画面。
- `/admin`：共用账号登录、自提权、运行控制、个人抽奖、公共内容处置、邀请状态和确定性重置。

D-037 已将寄语/时光胶囊从三端下线：锁色后连续播放确认与入轨动画并直接进入现场；`/admin` 在节目支持阶段控制无放回个人抽奖，`/screen` 仅展示获奖星号及静态降级。当前视觉不使用怀士堂线稿；动画边界以 [`../docs/VISUAL_GUIDE.md`](../docs/VISUAL_GUIDE.md) 为准。

> D-037 协议 v2 是现行产品路径；v1/G5 只作历史。前端仅在能力发现确认 `V2_ACTIVE` 后挂载 v2，结构与当前验收状态见 [`../docs/README.md`](../docs/README.md)。

G5-06 的手机端布局会监听 `visualViewport`：软键盘压缩可视高度时隐藏遥测和装饰层，保留当前输入与主操作。节目互动栏在 `星程` 页第 4 阶段起固定于内容区底部；礼物半屏面板使用可恢复的键盘焦点闭环。自动化覆盖 375px 小屏、390×420 键盘剩余高度、横屏、125% 字号和至少 44px 触控区域，vivo X300 真机体验仍由项目负责人验收。

带固定合成 `token` 的 `/welcome` 入口会在应用启动时把令牌暂存在当前页面内存，并立即从地址栏和当前历史项清除；不会写入本地存储。刷新导致内存入口丢失时，需要重新轻触或扫码。

所有请求使用相对 `/api`，Cookie 由浏览器同源携带；WebSocket 从当前页面 host 推导 `/ws`。`/welcome` 使用经参与者会话授权的 `participant` 流，`/screen` 与当前 `/admin` 使用隐私安全的 `screen` 流；客户端在完整快照与实时连接同步前阻止业务写入，断线期间不建立离线发送队列。重连顺序为“先取快照，再携带 `resetEpoch` 与 `afterEventSeq` 建立实时连接”。参与者私有状态不写入浏览器持久存储。

为满足 G4 的 300 人扇出边界，运行阶段、状态、节目、弹幕暂停和礼物热度等公开事实先按 `resetEpoch + eventSeq` 在本地投影；私有参与者失效通知和需要完整权威校正的公共事件使用合并快照刷新，避免每个运行事件让 300 个参与者同时拉快照。任何晚到且高水位更旧的快照都不得覆盖新事件，本地投影也不能替代重连时的完整权威快照。

## 本地运行

请从仓库根目录运行：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

构建检查：

```bash
pnpm --dir frontend build
pnpm test:load
```
