# 视觉资产生成工作流（ai-artist · 项目版）

上游 ai-artist（6000+ 提示词库、生图脚本）未随环境安装。本技能固化本项目自建资产的硬约束与可用路径；素材规则以 `docs/VISUAL_GUIDE.md` §2.3/§8.5 与 D-030/D-031 为准。

## 1. 硬约束

- 只允许**原创**素材；不复制去年项目或授权不明资源。
- 运行时**本地打包**，页面加载不得向官网/第三方拉取图片（D-031 学院 PNG 是唯一已授权例外，SHA-256 `5E665D84…`）。
- 新素材必须登记：名称、来源、作者/生成方式、许可证、用途，写入 VISUAL_GUIDE 或 DECISIONS。
- 压缩验收后才进 `frontend/src/assets/`：记录最终体积与 SHA-256。
- 星云纹理服务于 D-030 金标（前/中/后分层 Canvas 合成层），只作氛围，不代表参与人数。

## 2. 可用路径（按优先级）

1. **程序化生成（首选，无外部依赖）**：Canvas/SVG/CSS 生成星云颗粒、速度线、光晕。确定性种子、低 DOM、合成友好——与本项目技术栈一致。
2. **项目负责人提供素材**：如 D-031 学院 PNG 一样由负责人授权后引入，登记 SHA-256。
3. **外部生图**：本机未配置任何图像生成 API/模型。若未来配置，须先经负责人确认供应商、授权与隐私边界；AI 不得擅自调用外部服务。

## 3. 程序化星云纹理示例方向

- 多频叠加噪声（价值噪声/分形）+ 径向渐变（中心最亮、向外单调衰减，D-031）。
- 只动 `transform`/`opacity`；reduced-motion 下为同一确定性静态终态。
- 输出：小尺寸纹理（≤1024px、WebP），配合前端分层缩放；不要超大位图。

## 4. 验收清单

- [ ] 原创性可证明；许可证明确。
- [ ] 压缩体积可接受（纹理单个 ≤200KB 目标）；记录 SHA-256。
- [ ] 不包含真实姓名、学号、令牌或可识别信息。
- [ ] reduced-motion 下不依赖该资产承载信息。
- [ ] 构建产物无新增外部 URL。
