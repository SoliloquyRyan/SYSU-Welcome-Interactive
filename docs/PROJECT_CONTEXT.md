# 迎新晚会互动系统：项目上下文

> 状态：团队工作初版（v0.1）  
> 适用对象：五人项目组及参与协作的 AI  
> 说明：本文记录团队已定的开发基线和仍待确认的事项，不代表学院已正式审批。标为“待确认”的事项，在负责人确认前不得当作定案。

## 1. 项目目标

为智能工程学院迎新晚会建设一套手机 H5、后台控制台与舞台大屏联动的互动系统。实体明信片式邀请函既是迎新纪念物，也是进入“星际成长”体验的入口；新生完成六阶段互动后，可形成个人星际档案和匿名化的集体星图。

项目优先保证：进入简单、现场可控、内容先审后播、故障可降级、数据最小化。

## 2. 当前工作基线

以下内容是团队当前统一的设计与开发基线；是否纳入最终正式方案，仍以学院审核结果为准：

- NFC 明信片为主要触达方式，二维码为 NFC 不可用时的兼容备用。
- NFC 与二维码进入同一个 H5，不得形成两套账号、积分或互动记录。
- 二维码只解决 NFC 兼容问题；网站、服务器或网络故障由备用网络、延迟汇总和预渲染素材处理。
- 互动沿用六阶段主线：身份激活、未来寄语、星星集结、节目应援与弹幕、星光成长、结尾回响与个人档案。
- 动力值用于节目应援，星光值用于记录参与成长；两者互不兑换。
- 寄语和弹幕只有经过人工终审后才能进入公共大屏。
- 只处理活动必需的数据；可识别个人的数据及原始互动数据原则上在活动结束后 30 天内清理。

## 3. 六阶段体验

| 阶段 | 参与者体验 | 现场输出 |
|---|---|---|
| 1. 轻触/扫码与身份激活 | 通过邀请函进入 H5，完成必要核验并生成个人星号 | 登录进度与匿名星点数量 |
| 2. 未来寄语 | 提交一条给未来自己的短句；是否公开须有明确提示 | 暂不公开完整内容 |
| 3. 星星集结 | 个人星星进入待启动状态，随主持人口令共同升空 | 星点汇聚成指定图形；具体图形待确认 |
| 4. 节目应援与弹幕 | 查看节目单、投入动力值、提交弹幕 | 节目热度与通过终审的弹幕 |
| 5. 星光成长 | 通过有效互动累计星光值 | 全场或区域的集体进度 |
| 6. 结尾回响与档案 | 查看经审核的寄语回响并生成个人档案 | 匿名寄语、关键词与谢幕画面 |

## 4. 交付范围

- **邀请函与入口**：明信片视觉、NFC/二维码编码规则、写入质检、发放与补卡流程。
- **手机 H5**：进入、核验、寄语、个人星星、节目单、动力值、弹幕、互动任务与个人档案。
- **后台控制台**：节目状态、双值规则、内容终审、数据监控、应急暂停和受控导出。
- **舞台大屏**：星星集结、节目热度、审核内容、集体星光进度和结尾回响。
- **现场运行**：主备网络与设备、Cue 表、审核席、人工协助、分级降级与活动后清理。

默认不包含支付、抽奖兑付、公开个人排行榜、自动发布未审内容、人脸识别或永久保存个人档案。若需加入，必须另行评估和确认。

## 5. 五人团队与 AI 协作

具体姓名待确认，先按职责槽位协作：

| 槽位 | 主要职责 |
|---|---|
| A. 项目/产品 | 需求、优先级、Issue、跨组沟通和最终产品验收 |
| B. 手机端前端 | 登录、个人页面、双值、寄语流程、兼容性和前端测试 |
| C. 后端/发布 | 数据库、接口、审核后台、权限、部署回退和数据清理 |
| D. 视觉/大屏 | 手机端与大屏视觉、动画、页面文案和公开内容流程 |
| E. 测试/NFC | 邀请函写入质检、二维码、真实设备、全流程和彩排验收 |

AI 可协助梳理需求、生成原型或代码、编写测试和维护文档，但必须遵守：

- 产品取舍、公开内容、数据导出和上线操作由人类负责人批准。
- AI 只使用模拟数据或已匿名化数据，不接收真实姓名、学号、原始寄语或弹幕。
- AI 产出必须经过对应职责成员复核，不得把建议写成学院正式决定。
- 影响多人开发的决定先写入 `DECISIONS.md`，再同步本文与 `REQUIREMENTS.md`，最后修改实现与测试。

现场主控、内容终审、人工协助和数据删除复核属于活动当天的运行职责，可由上述成员排班承担；具体人选必须在彩排前确认。

## 6. 已知约束

- NFC 和二维码必须落到同一个稳定入口，且手机端状态一致。
- 现场大屏只能接收聚合数据、匿名标识和已通过终审的内容。
- 六阶段中的关键切换由后台人工触发，并准备可直接播放的兜底素材。
- 明信片及 NFC 的采购、付款和供应商下单由外部负责；本组负责技术规格、入口配置、样品测试、写入流程和到货验收结论。
- “写给四年后的自己”目前是叙事表达，不等于获准保存数据四年。

## 7. 待确认

- 活动日期、预计人数、节目单和场地大屏参数。
- 邀请函采用通用入口还是“一人一卡一码”的个性化令牌。
- 身份核验字段、人工核验和访客模式。
- 动力值单次档位、单节目上限，以及星光值具体计分表。
- 寄语公开授权方式、是否录像/直播及其提示文案。
- 人工终审席位数量、终审负责人和紧急清屏权限。
- H5 域名、部署环境、服务器资源、备用网络和第三方服务。
- 个人档案开放期限；按当前基线不得超过活动后 30 天，延长需另行确认。
- 物料数量、预算、打样时间、发放方式和备用比例。
- 数据负责人、删除验收人及学院要求的审批或备案流程。
