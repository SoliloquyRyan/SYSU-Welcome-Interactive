# 项目上下文

> 状态：协议 v2 现行；最新决策 D-036（2026-08-15，V2-10 人工签核关闭，Demo v0 收口）。本页是"项目现状"的唯一来源；历史内容见 [`archive/`](./archive/README.md)。

## 1. 目标

为智能工程学院迎新晚会建设手机 H5（`/welcome`）、后台控制台（`/admin`）与舞台大屏（`/screen`）三端联动的互动系统。实体明信片式邀请函（NFC/二维码）是进入"星际成长"体验的入口；新生完成身份激活、星色锁定与时光胶囊决定后进入全场场景，形成个人星际档案与匿名集体星图。

优先级：进入简单 > 服务端状态可信 > 三端实时一致 > 现场可控 > 公开内容可快速处置 > 故障可恢复 > 数据最小化。

## 3. 协议 v2 主线（详见 PROTOCOL_V2）

1. 有效入口（NFC / 同令牌二维码 / 人工协助）先原子预留 300 个稳定 slot 之一，再完成激活并只发放一次 100 动力 + 20 星光；满员整笔拒绝。
2. 锁色后个人恒星立即加入公开星系；随后对时光胶囊做"提交（+20 星光）或跳过（0）"的持久决定。
3. 完成决定即进入当前全场状态；晚到者不重放历史阶段。
4. 全场只有 `ASSEMBLY → PROGRAM_SUPPORT → COOPERATIVE_LIGHT` 三场景；`COMPLETED` 是终态，不是第六场景。
5. `PAUSED` 冻结参与者写入但允许只读恢复；`COMPLETED` 关闭写入、允许本 epoch 已激活身份只读重认证。
6. 安全处置只指删除、屏蔽、清屏或撤下公开内容，不调整数值。

## 4. 三端体验

| 端 | 体验 |
|---|---|
| 手机 `/welcome` | 入场（寻星 → 选色 → 胶囊决定）→ 沉浸式流动星系 + 单一高透微角操作坞；本人星突出并显示星号 |
| 大屏 `/screen` | 单 Canvas 最多 300 颗真实恒星；`PROGRAM_SUPPORT` 为 OBS 透明源；胶囊插播/终章按固定视觉优先级 |
| 后台 `/admin` | 共用账号登录 + 自提权；三场景控制、节目选择、胶囊人工插入（≤6 条）、弹幕处置、匿名漏斗、确定性重置 |

## 5. 边界与延期事项

- Demo v0：本地局域网、固定合成数据、一条命令启动三端并输出 URL/二维码/凭据。
- 明确不做：支付/抽奖/兑奖、公开个人排行榜、人脸识别、四年保存、真实名单、实体 NFC 写卡、邀请函印刷、公网部署、真实 AI 审核、重型 3D。
- 正式版待确认：活动日期/人数/节目单、场地大屏参数、真实名单与核验授权、H5 域名与部署、物料预算、数据负责人与删除流程、学院 Logo 矢量母版授权。

## 6. 协作与安全边界

- 项目负责人单人维护；AI 可协助需求、原型、代码、测试与文档。
- AI 只使用合成或匿名化数据；不接收真实姓名、学号、令牌、胶囊或弹幕正文。
- AI 产出须由负责人复核；影响实现或验收的决定先写入 [`DECISIONS.md`](./DECISIONS.md)。
- 未授权不提交、不推送（见 DECISIONS D-014）。
