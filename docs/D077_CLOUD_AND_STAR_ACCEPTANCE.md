# D-077 星色、星体尺度与云层聚散

状态：2026-09-08，本地实现与审片；未发布服务器。负责人认可 D-076 总体构图，要求大屏各人的星色更清楚、手机星体缩小、星云像云一样消散后重新形成，并继续抬亮背景暗部。

## 本轮实现

- 大屏从参与者既有 `displayColor` 绘制星体，减少星核与光晕混入白色的比例；细小高光仍近白。星位、人数、选色数据和装饰星语义保持。审片样例直接调用正式 `starTemperatureColor`，覆盖 2400–12000K 的珊瑚、琥珀、暖白与冷蓝色谱。
- 手机轨道个人星体及其光晕的尺度由 0.24 调至 0.17，缩小约 29%。初次选色时的大星体仍可清楚辨色，进入轨道时平滑收小，星号继续跟随。
- 星云使用共享 `stellar-cloud.js`，在原旋臂的随流坐标里加入局部密度和纹理扰动。不同云块以错开的相位变薄、聚拢，整体星云仍沿 D-076 原路径流动；靠近核心时逐渐减少扰动，保持核心稳定。没有整体闪烁或新增帧循环。
- GPU 与 Canvas2D 背景同步抬亮为墨蓝渐层。1920×990 审片截图的 (24,24) 角落像素由 RGB(6,10,16) 提高到 RGB(14,21,31)，星云和正文仍保留亮度层次；该像素数值不等同于 LED 场馆亮度。
- Canvas 回退使用缓存的 96×96 平滑密度遮罩，每秒最多更新 10 个材质时刻，避免逐帧重算 1024×1024 噪声。它保留局部消散与汇聚，细纹理变形比 WebGL 简化。减少动态模式保持固定时刻、静止画面；OBS 节目透明终点仍为零 alpha。
