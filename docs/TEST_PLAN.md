> 状态：D-022 已冻结 G0～G4 测试证据；D-023 的 G5 手机端目标尚未实现，需新增迁移、浏览器与隐私证据。

> 说明：G2 已建立功能与服务端自动化基线；G3 收口真实浏览器端到端与恢复证据，G4 单独承担且已通过 300 人本机协议负载专项，G5 承担下一阶段视觉统一。实体 NFC、印刷、公网、真实数据、正式场馆和现场硬件属于正式版延期事项。

## 1. 测试目标

Demo v0 必须证明以下事实，而不只是“页面能打开”：

1. 三端共享同一份服务端权威状态，并能在同一局域网的不同设备或标签页实时联动。
2. 六阶段均可真实操作、持久化、恢复和确定性重置。
3. 重复点击、超时重试、多设备并发和服务重启不会重复建号、重复扣款、重复奖励或产生负余额。
4. D-022 继续证明旧未来寄语不进入公共面；G5 必须另证只有已确认公开范围且经人工选中的时光胶囊可以上屏，未选中和已撤下正文不能泄露。
5. G4 使用 300 个固定合成参与者证明阶段、礼物、弹幕和协同点亮更新的端到端传播延迟 p95 不超过 2 秒；D-021 记录的 2026-08-10 提交前 `pnpm verify:g4` 全门已经通过，该结论不得由 G3 的小规模 smoke 代替。
6. G3 证明 Windows Chrome、Windows Edge、1920×1080 和减少动态效果模式可完成核心流程；项目负责人也已在 vivo X300 默认浏览器完成人工核心旅程。

## 2. 测试原则

- 只使用固定种子中的虚构姓名、六位 Demo 码、随机令牌、虚构节目和虚拟礼物。
- 不在仓库、截图、录屏、日志或缺陷单中记录真实姓名、学号、手机号、完整令牌、六位 Demo 码、Cookie、口令、私密寄语正文或数据库文件。邀请入口 URL 可按设计承载完整随机令牌，但不得原样进入测试证据；展示证据前必须脱敏。
- 所有业务写命令都必须验证幂等；阶段敏感命令同时验证 `stageRevision` 与 `resetEpoch`。
- 断线期间禁止业务写入，不在浏览器中排队补交；重连后先获取完整权威快照，再接收新事件。
- WebSocket 只广播已经提交的事实。装饰轨迹可丢弃，不得以重放动画代替状态恢复。
- 后台使用共用账号，登录会话可自行取得能力。测试应验证服务端检查当前角色，但不得把该机制描述为个人身份审计或可靠的最小权限。

## 4. 环境与数据

| 环境 | 用途 | 当前要求 |
|---|---|---|
| 单机多标签页 | 快速功能和状态检查 | `/welcome`、`/admin`、`/screen` 同源运行 |
| 同一局域网多设备 | vivo 与电脑联动 | 使用启动器输出的实际局域网地址，不硬编码 `localhost` |
| 自动化环境 | 接口、幂等、重连和负载 | 独立临时数据库，固定种子，可重复清理 |

测试数据固定包含：

- 300 个合成参与者，每人一个高熵随机邀请令牌、虚构姓名和六位 Demo 码；
- 固定虚构节目与四档礼物：微光 5、信标 10、星轨 20、星舰 50；
- 可命中敏感词、链接、联系方式、长度和频率规则的合成弹幕；
- 固定重置种子，便于比较每次执行结果。

## 9. 三端端到端场景

1. 启动系统并记录启动器输出的手机、后台和大屏地址。
2. 用两个设备以同一合成参与者登录，确认共享状态。
3. 完成身份激活和私密未来寄语，确认大屏只增加匿名计数。
4. 后台在排练模式跳到星星阶段，参与者启动星星，大屏出现匿名节点。
5. 切换到节目阶段，连续赠礼并发送合规与违规弹幕，核对余额、热度、实时发布和规则拒绝。
6. 后台删除弹幕、屏蔽来源并清屏，确认所有客户端收敛到同一状态。
7. 完成协同点亮与最终档案，确认个人信息和公共聚合边界。
8. 在关键写入前后分别制造断网、重复点击、页面刷新和服务重启，验证幂等与恢复。
9. 执行确定性重置，确认旧会话失效、旧事件丢弃、固定种子可复现。

## 12. 隐私与安全检查

- D-022 基线：大屏快照、公共 WebSocket、服务端日志及非对应会话响应不得出现姓名、六位 Demo 码、完整令牌、Cookie、密码或旧私密寄语。
- G5 目标：完整学号、身份映射、未选中或已撤下的时光胶囊不得进入大屏、公共事件、日志或非对应会话；公开星号的可关联风险必须如实说明。
- 参与者本人激活请求可以按入口模式携带令牌或备用核验字段，但这些信息不得进入公共页面、跨会话响应或测试证据。
- 后台与参与者会话使用 `HttpOnly`、`SameSite` Cookie；局域网 Demo 校验 `Origin` 与 `Host`。
- 局域网 HTTP 不提供传输机密性，只能在可信本地网络使用；不得宣称达到正式生产安全等级。
- 输入执行长度、格式、频率和常见注入防护；错误响应不回显敏感值。
- 数据库与本地凭据位于被忽略的运行目录，不进入版本控制。
