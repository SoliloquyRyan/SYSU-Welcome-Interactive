# 下一届现场一页启动单

## 发布前

1. 从 GitHub 克隆仓库，确认 commit 和 `docs/POST_EVENT_REVIEW_20260920.md` 版本。
2. 准备脱敏 `.env`，正式名单、运行密钥、NFC 映射放在代码目录之外。
3. 运行：

```text
pnpm install
pnpm docs:check
pnpm typecheck
pnpm test
pnpm build:formal
```

4. 检查 `/api/health`、`/api/ready`、`/welcome`、`/screen`、`/admin`；核对节目目录、schema、OBS 场景和音频文件。

## 开场前必须做的断网演练

- 断开主网络，保留主控电脑、LED、OBS 和备用热点。
- 打开离线舞台备用入口，手动完成开场、至少一个节目、一个互动标题、颁奖和结束页。
- 恢复网络，确认在线模式重新取快照，不重复建号、不重复发礼物、不重复揭晓奖项。
- 任一环节失败，标记 `PENDING`，由现场负责人决定是否继续；不要在正式轮次直接 reset 或清库。

## 现场角色

| 角色 | 唯一职责 |
| --- | --- |
| 主控 | 轮次、节目执行、互动开关、离线/在线模式决定 |
| 主持 | 只读主持口令和当前节目，不自行猜场景 |
| OBS 操作员 | 场景、音频、浏览器源和桥接回读 |
| 网络/设备负责人 | 主 Wi-Fi、备用热点、LED、线缆、电源、备用电脑 |
| NFC/入场负责人 | 样卡、抽检、补卡和手机入口 |

## 现场停止条件

手机空白、后台未连接、大屏无法恢复主题、OBS 桥接不可用、错误音频触发抢答、抢答无法暂停/续播、权限或名单异常时，先停写卡和现场推进，切到纸面流程/离线舞台，再由主控和现场负责人共同恢复。

## 绝对不能进入 GitHub 的内容

正式名单、学号、密码、OBS WebSocket 密码、桥接令牌、NFC 映射、Cookie、真实数据库、聊天导出和含身份信息的截图/录屏。
