# D-084 四周尘云与细淡受光边缘

2026-09-09，负责人先要求背景更深、加一点白色轮廓、赋予宇宙实物形态，随后补充四周采用同样处理，并指出中间稿过深、喧宾夺主。最终保留四周气体云和暗尘埃的结构，同时降低雾团浓度与轮廓对比，以中央银河和星星为视觉重点。本轮仅本地实现与审片，未发布服务器。

## 最终实现

- 背景四周采用不规则气体云、透黑尘埃带和局部银白受光边缘。以密度变化和方向性受光表现体积，纹理使用双线性采样消除锯齿；这是一幅艺术化远景，并非真实天区测绘。
- 按最后一次反馈，气体层强度收至中间稿的 56%，白边强度收至 42%。黑色底调与中央主星云保持，主星云继续沿原旋臂流动、消散和重聚。
- 背景横竖屏分别缓存一份纹理，避免手机侧边被裁掉或纹理被拉长；方向变化时复用已有 GPU 纹理上传相应缓存。每个渲染器仍仅有原来的一张背景纹理，无新增动画循环或依赖。
- 范围为 `stellar-sky.js`、`stellar-nebula.js`、`galactic-medium.js` 及预览版本标签。参与者星色、尺度、人数、业务和主银河的运动算法保持。
