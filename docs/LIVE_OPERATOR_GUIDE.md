本页适用于 **D-107 发布 / schema 21**。沿用已认可 D-106 界面；服务器发布实际结果见 [D-107](./D107_RELEASE_AND_HOST_CUES.md)，主持对稿见 [动画与口令单](./HOST_CUE_GUIDE.md)。[本轮改动和验收](./D105_AUDIENCE_PROGRAMS_AND_AUDIO.md) · [节目目录](./EVENT_PROGRAM_2026.md) · [恢复与发布基线](./D100_SERVER_AND_GITHUB_RELEASE.md)

## 开场前

1. 确认 `/welcome`、`/admin`、`/screen` 来自同一版本，控台显示“实时已连接”。
2. 待开始时在左侧“节目编排”点击“载入本场节目单”。检查 **25 项**：19 个表演节目、3 个互动环节，以及节目颁奖、负责人讲话、校园图鉴颁奖。核对表演者后点击“确认应用 25 项”。已经在用的旧目录不会被新版前端自动替换。
3. 左侧选择或点击目录只表示待执行；中央显示当前节目、下一项和待执行节目。点击“设为当前节目”或明确的下一项按钮才改变现场。OBS 的节目素材需由操作员同步切换。
4. 报幕点击“报幕／主题背景”，大屏只保留学院标志、星城和星光；点击“返回节目”恢复当前节目。负责人讲话保留独立标题。伴奏节目使用 `/screen` 完整星城；有独立视频或图片的节目使用 `/screen?media=overlay` 透明叠加。设置页 `/screen?settings=1` 可选择完整动效、跟随系统或静态显示，以及背景和音乐光尘。
5. 手机检查礼物 1/5/10/20 动力、数量、余额、个人星色和高级弹幕解锁确认；《光年之外》和非表演环节不接收礼物。
6. 排练时预览终章、检查获奖草稿和名单分页。排练数据管理默认折叠。数据复位会清除当前合成轮次，不能把它当成修复 UI 的方式。

## 节目背景与观众星空

10 个无独立画面的节目各有专属背景，完整索引见 [D-105](./D105_AUDIENCE_PROGRAMS_AND_AUDIO.md#节目索引)。节目名称及表演者全程显示，均读取当前后台目录；中文几何标题已接入负责人提供的方线体；英文 Orbitron、抒情 / 器乐宋体，姓名仍用 Noto。9 个已有视频 / 图片的节目继续使用 OBS 原素材和短时报幕。

推荐共用 `/screen?media=overlay`：已配置独立画面的节目透明叠加，无画面节目和未知 ID 自动显示完整主题；HOST 也显示完整主题。回到 PROGRAM 后恢复当前节目对应模式。OBS 的播放、停止与切场由操作员完成。

背景星数等于已锁定星色的入场人数，上限 300；手机掉线不减星，刷新不补播入场或过期礼物。空场没有装饰星，人数不足时不要通过增加装饰星“补满”。微尘与反光承担环境层次。

### 现场音源检查

启动前运行 `pnpm obs:audio --list-inputs` 或 `pnpm obs:audio --check`，核对当前场景、静音、输出轨道和选中输入。两项均只读。正式运行用 `pnpm obs:audio`；桥接退出、断线或没有有效音源时环境自动回落。

对于现场乐器或调音台，在本机 `节目素材对应.json` 对应节目中增加 `liveInputs: ["OBS 中准确的输入名称"]`。仅加入该节目明确使用的输入，保留 `media`；不自动加入主持话筒或桌面声音。输入须在当前播出场景启用（或为明确配置的全局音频输入）、未静音、路由至指定轨道且不是仅监听。可用 `--track 1` 显式指定轨道。

当前保存的正式集合尚未接入真实调音台，须在接线后重新检查并联排。受控软件音源通过不等于硬件已验证。

## 控台分区

| 区域 | 用途 |
| --- | --- |
| 顶部 | 模式、运行状态、连接状态、全场暂停／恢复、推进主场景 |
| 左侧 | 节目目录，正在进行／待执行／下一项，明确执行按钮 |
| 中央 | 公共大屏的静态状态预览、当前节目和下一步提示 |
| 右侧 | 当前环节的抽取、投票、抢答、主持与颁奖控制 |
| 下方 | 弹幕审核、现场进度、操作回执与排练维护 |

中央预览直接读取公共大屏数据，不展示后台私密名单；它关闭环境动画和音量调制。OBS 中的原节目视频及最终合成效果在 OBS 查看。

## 现场顺序

| 阶段 | 主控动作 | 三端预期 |
| --- | --- | --- |
| 开始 | 在“开始模式”选择现场，点击“开始活动”，核对确认框中的模式和星海集结 | 自动依次设置模式、开始活动，取得新状态后才继续 |
| 集结进入节目 | 点击“推进下一场景”并确认，再选择首个节目并执行 | 大屏沿用 12 秒开场，手机沿用 2.4 秒；实时业务状态立即更新 |
| 正式节目 | 浏览目录后“设为当前节目”；在 OBS 切到对应素材 | 同步标题、表演者、主题和礼物数量；简化星城给内容留白 |
| 互动环节一／三 | 执行该环节，填写提示，开放抢答 | 三秒倒计时后按服务端首份有效响应锁定；学生看公开星号 |
| 互动环节二 | 开启观众抽取，逐位抽取 2～12 位；同一面板核对候选星号和投票标题，点击“完成抽取并开放投票” | 先收起抽取，确认成功后才开放投票；公开端不显示姓名 |
| 投票揭晓 | 点击“揭晓投票结果”并确认 | 服务端发布后公开票数；动画不决定结果 |
| 互动结束 | 抢答已经锁定或投票已经揭晓，且下一项允许切换时，点击“收起互动并进入下一项”并确认 | 收起结果后再切下一项；未完成互动不提供此快捷操作 |
| 节目颁奖 | 执行节目颁奖环节，核对有效动力值与获奖草稿；按需要调整后保存 | 未揭晓名单仍为后台草稿；点击揭晓并明确确认后才公开 |
| 讲话与校园图鉴 | 按 25 项目录执行讲话、对应颁奖；核对奖项、分页和公开名单 | 主持雾蓝、颁奖暖金紫；大屏和手机场景主题对应 |
| 协同点亮 | 全部节目和互动完成后推进主场景并确认 | 城市淡出回到星河，手机开放协同点亮 |
| 谢幕 | 点击“结束并锁定终章”，确认就绪提示 | 业务立即进入只读终态；片尾播放一轮后定格 |

**合并操作中途停止时**，回执会列出“已确认”和“待核对／待完成”。先核对当前状态，再使用单项操作继续；不要假设前一步已经回滚，也不要反复点击整组操作。例如抽取已收起但投票开放失败，可检查候选与当前环节，再单独点击“开放观众投票”。已离线、状态版本过期或权限不足时不自动重试。

## 音乐光尘

1. 在本机 OBS 的“工具 → WebSocket 服务器设置”启用服务器，保留身份验证。使用同一 Windows 账号的现有 Node 环境。
2. 从项目根目录运行 `pnpm obs:audio --check`。默认读取本机 OBS 鉴权配置与项目旁 `OBS-迎新晚会-20260913/节目素材对应.json`。密码只在内存使用，不粘贴到浏览器地址或现场文档。
3. 检查成功后运行 `pnpm obs:audio` 并保持终端运行；Ctrl+C 停止。素材路径变化时用 `--mapping "绝对路径/节目素材对应.json"` 指定新映射，音轨不是 1 时用 `--track 2` 等指定实际输出轨。
4. 桥接只读取当前播出场景中启用、未静音、进入指定输出轨的已映射本地媒体；麦克风、桌面音频、仅预览场景和仅监听源不会驱动城市。
5. 大屏在 OBS Browser Source 中运行才接收联动。普通浏览器、后台预览和手机保留环境效果；大屏 `audio=off` 可临时停用联动，`motion=reduced` 完全静态。
6. 控制事件仅有版本、归一化强度和可用状态，至多 20 次／秒。音乐改变细星亮度、轻尘速度和边缘光，文字与卡片不跟随跳动。超过 500ms 没有数据后，约 800ms 内退回环境效果。全场暂停、页面隐藏和转场时重置调制。

程序不代替 OBS 播放、切场或音量混音。大屏缺少音量数据仍可正常显示现场。

## 礼物、弹幕与隐私

- 礼物数量 1～20，余额不足时整批失败，不产生部分扣费。四档公屏卡片读取当前节目累计数量。
- 微光闪星（0.8 秒）、信标双光波（1.4 秒）、星轨流星（1.6 秒）、小星舰星色尾焰（2.4 秒）只在服务器确认送礼后出现。批量送礼一次效果，账目按实际数量记录；高峰同类同色合并，大屏最多 6 个、手机最多 2 个，队列最多 12 批且最长等 3 秒。第三次及之后星舰同样可见。刷新、重连和隐藏恢复不补播。动画缺失时先核对余额和账目，不重复送礼补画面。
- 高级弹幕本场首次解锁需 10 动力，确认层显示款式、费用和余额；同款再次使用不重复扣解锁费。
- 私密姓名、完整学号、邀请令牌与后台信息不传入公共预览。装饰星点不参与人数统计。手机个人档案仅展示本人记录。
- 及时审核弹幕。片尾保留全场计数，但已撤下或已屏蔽内容不重新公开，不能将旧版“所有历史正文都会重新显示”的说明用于当前版本。

## 异常处理

- **正在恢复同步**：等连接恢复并读取最新状态后再操作；恢复不会自动补交上次请求。
- **投票无法开放**：检查当前确为对应互动、候选 2～12 位、抽取投影已收起且没有其他进行中的互动。
- **揭晓或颁奖没有变化**：核对确认框、权限和操作回执，刷新读取当前服务器发布状态。
- **画面太繁或现场亮度过高**：可切静态或关闭音乐光尘；调整 OBS 最终亮度时同时核对中文正文和星号可读性。
- **暂停／应急**：使用顶部全场暂停；OBS 操作员按场务口令切应急素材。恢复后核对节目与互动状态再继续。
- **版本或数据异常**：先保存证据并检查前后端版本和 schema 21；不要通过复位数据或覆盖重要历史版本修复显示问题。

真实 iOS／Android 微信、场馆 LED、现场网络和主持口令仍需实机联排。本机合成 OBS 测试的实际范围和数据见 D-104 验收记录。
