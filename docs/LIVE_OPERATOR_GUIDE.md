# 迎新晚会主控操作单

当前代码基线为 D-089 / schema 19，本轮尚未发布。服务器若仍是 D-087 / schema 17，应继续使用服务器随包操作单，不能把本页的新按钮当作已经上线。

## 开场前

1. 确认手机 `/welcome`、控台 `/admin`、大屏 `/screen` 三端来自同一版本，后台显示“权威实时已连接”。
2. 在 `READY` 状态载入本场节目单，预览确认 19 个正式节目与互动环节 A/B/C，再应用。正式节目编号 `01`～`19`，互动环节不计入节目数量。
3. 检查礼物档位为 1、5、10、20，手机可选择数量；用合成账号验证“我的星色”和一款高级弹幕确认层。
4. 排练大屏 `motion=full` 与 `motion=reduced`；确认节目态前三档礼物数量不遮挡报幕和弹幕，20 动力星舰在完整动效下清楚、静态模式下可读。
5. 预览终章，核对节目表演者、各节目礼物值、四档礼物总量和全场弹幕。预览不结束活动。

## 现场顺序

| 阶段 | 主控动作 | 三端预期 |
| --- | --- | --- |
| 开始 | 选择现场模式，点击“开始活动” | 大屏进入星海集结，手机保持个人进度 |
| 正式节目 | 切换当前节目 | 手机开放弹幕和礼物；礼物按数量完整扣费；大屏显示前三档当前节目数量 |
| 互动环节 A | 切换到 A，填写提示，开放抢答 | 手机出现抢答按钮；服务端锁定第一响应；大屏和控台显示同一星号 |
| 互动环节 B | 切换到 B，开启上台观众抽取，逐位抽取 2～12 位，完成抽取；填写投票标题并开放投票 | 大屏依次显示候选星号；手机一人一票且不见实时票数；控台可查看票数 |
| B 揭晓 | 点击“揭晓投票结果”，主持完成后关闭本轮互动 | 大屏显示各候选票数与比例；关闭后才能继续切换项目 |
| 互动环节 C | 切换到 C，填写提示，开放抢答 | 与 A 相同，形成独立轮次 |
| 协同点亮 | 确认所有节目与互动结束后推进 | 手机开放协同点亮，大屏显示权威完成人数 |
| 谢幕 | 现场模式点击“结束并锁定终章” | 业务立即进入只读终态；大屏播放节目与礼物值、弹幕与礼物总量，再定格 |

## 互动控制原则

- 抢答与投票结果以服务端事务为准。主控不要凭手机动画口头宣布结果，应等待大屏或控台出现权威星号。
- 抢答开放后，第一份有效响应会立即锁定本轮；需要重开时先关闭本轮，再次开放会生成新轮次。
- B 至少抽取两位上台观众后才能开放投票，最多 12 位。姓名只在授权控台显示，大屏和手机仅显示公开星号。
- 每位已入场参与者每轮只能投一票。投票期间手机与大屏隐藏候选票数；点击揭晓后公开。
- 切换节目、切换场景、暂停或结束会关闭正在进行的抢答或投票。观众抽取记录保留；只有排练模式可清空。
- 互动环节不接收礼物。弹幕仍可使用，主控可暂停新弹幕、撤下单条或屏蔽来源。

## 礼物与弹幕

- 礼物数量范围 1～20。余额不足时整批失败，不产生部分礼物、部分扣费或部分动画。
- 前三档礼物在大屏右下持续显示当前节目累计数量；节目切换后读取新节目的权威数量。
- 20 动力星舰每次发送播放一条批次动画并显示数量。刷新、重连和页面隐藏恢复不补播旧动画，账目与数量仍恢复。
- “我的星色”由服务端读取参与者已锁定颜色。三款高级弹幕首次使用前扣 10 动力，手机必须显示款式、费用、余额和明确确认；同款本场再次发送不重复扣解锁费。
- 谢幕读取本场全部弹幕，包括后来被安全撤下的内容事实；现场审核仍应及时处理不适合公开展示的文本。

## 异常处理

- 控台或手机显示“正在恢复同步”：停止连续点击，等待重新连接并读取最新 revision。
- 抢答未锁定：确认当前项目确为 A 或 C、主控已经开放、手机已入场且现场仍在节目支持阶段。
- 投票按钮缺失：确认 B 的抽取大屏已经关闭、候选不少于两位、投票已开放。
- 礼物无动画：先核对服务端数量和余额；动画缺失不代表交易失败，不能重复点击补画面。
- 谢幕数据缺失：确认前后端均为 D-089 且数据库为 schema 19；不要用新前端连接旧后端。
