# 迎新晚会主控操作单 · D-119

本页适用于 D-119 / schema 24。当前轮次以后台实时状态为准。主持台词与计时见[主持人动画对稿单](./HOST_CUE_GUIDE.md)，最终修复见 [D-119](./D119_IMPLEMENTATION.md)。不要将真实名单写入演练记录。

## 最终现场流程

1. 主控点击“报幕／主题背景”，OBS 保持 `00 开场与集结`，主持人完成报幕。
2. 在节目页或互动页选择下一项，点击“执行选中项”；OBS 自动切至对应节目或颁奖场景。
3. 互动一选择音频，点击“布置 10 秒自动抢答”；本机桥接从头播放 mix，确认开始播放后服务器同步 10 秒倒数。答案只在后台显示。
4. 颁奖页选择“节目颁奖”或“校园图鉴颁奖”，选择奖项、展示奖项，再按口令“揭晓名单”。大屏只显示姓名或节目奖标题，不显示内部备注。
5. 积分前 20 分三页，用上一页/下一页切换；刷新保持当前页。
6. 游客如需核验学生身份，在手机“档案”中操作。
7. 每次发布必须刷新正在运行的 OBS 浏览器源；仅刷新网页控制台不会刷新 OBS 缓存。已开始的节目之后不再展示开场到场人数。

## 开场前

1. 检查手机、大屏和控台使用同一发布版本。控台显示实时已连接，核对实际模式、状态、轮次、25 项目录和 19 个表演节目。已结束的旧轮次需要主控明确归档并重置，才会回到待开始。
2. NFC 全部写入统一手机网址。学生姓名与 8 位学号必须匹配正式名单；工作人员按分发指引在相同姓名、学号字段填写账号信息；游客使用“游客参与”，每轮最多 94 人。不要把主控口令交给应援人员。
3. 核对六类校园奖项草稿：15、5、10、3、3、20 人；摄影三人均颁奖。确认草稿不等于揭晓，公开画面以逐项揭晓为准。
4. 在 OBS 核对原视频、伴奏、三组互动 `mix` 和现场音源。普通节目媒体仍由操作员执行；互动一在控台布置后由本机桥接自动触发对应 `mix`。先用独立排练配置验证，不在正式库中制造测试送礼或投票。
5. 确认学院标志、标题和姓名在 LED 上可读。微信、音频调音台与 LED 的实体联排另行记录。

## 开始与报幕

- 开场待机和报幕初始阶段在大屏右上角显示“已入场”人数；锁色后计入已入场人数，断线不会减人。第一次执行节目后人数牌自动隐藏，后续报幕和节目不再显示人数。
- 主持口令后选择节目并明确执行网页操作；网页确认后本机 OBS 桥接自动切换到对应节目场景，普通节目媒体的播放／停止仍由操作员按口令控制。手机始终使用统一竖版背景，业务状态即时更新。
- 每次报幕点“报幕／主题背景”，显示 2026迎新晚会及主题副标题，暂停送礼。
- 互动页已合并为一块主控面板：报幕／主题背景、返回节目、执行选中项、下一项、互动 A/B/C、音频答案与收尾均在同一页完成。点击报幕后 cue 为 `HOST`，桥接确认 OBS 为 `00 开场与集结`；主持完成报幕后再点“执行选中项”。
- 浏览节目或编辑候选只做准备；必须明确点“执行选中项”或“返回节目”才执行服务器节目切换，随后由 OBS 桥接同步对应场景。

## 互动与颁奖

| 环节 | 执行动作 | 收尾 |
| --- | --- | --- |
| 互动一 | 布置题目并选 `mix`；点击布置后桥接自动触发 OBS 从头播放，播放开始后自动倒数 10 秒 | 首次抢到自动暂停；答错点“继续抢答”续播，答对或主控关闭 |
| 互动二 | 设置 2～12 位选手标签与题目，确认选手并开放投票。候选无需观众账号，投票时不可修改 | 关闭投票并确认揭晓；随后收起结果，或使用收起互动并进入下一项 |
| 互动三 | 执行线下互动背景，主持人组织现场活动 | 选择下一节目并明确执行；不开放抢答 |
| 节目颁奖 | 核对正式动力前三名；并列时按现场确定的结果调整并留下记录 | 确认揭晓；工作人员、游客应援不计入排名 |
| 校园颁奖 | 核对并确认草稿，选择当前奖项，再确认揭晓 | 每页念完再翻页；修改已公开名单前先收起 |

组合操作按顺序完成，前一步成功并取得最新状态才执行下一步。中途失败会停止并显示已完成步骤；先核对控台状态，再从尚未完成的步骤继续，避免重复执行。

《光年之外》为查无此队，保留完整六位成员介绍，继续禁礼物。讲话使用独立标题。

## 音乐、弹幕与礼物

- 本机 `pnpm obs:audio --check` 只读检查已映射音源，`pnpm obs:audio` 启动音乐动效和互动一桥接。普通节目音量不会被自动调整。
- 互动一的 `mix` 由同一桥接程序监听；先在控台完成“布置 10 秒自动抢答”，桥接会自动让 OBS 从头播放，收到播放开始事件后服务器才进入倒数。桥接断开时后台显示不可用，不伪造开放状态。
- `hint`、`answer` 和普通节目音乐不会触发互动一；音频自然结束只更新音频状态，主控仍须关闭本轮。
- 现场调音台和乐器必须明确配置到节目映射的 `liveInputs`；主持话筒、桌面声音不自动纳入。
- 开场有人完成入场时，大屏播放一次短流星划过效果；节目开始后不再用入场流星打断节目画面。节目与报幕中的观众星平时透明，确认礼物后局部短闪。音乐只影响薄雾、微尘、轮廓光；手机不会接收音频数据。
- 四档礼物有界合并，统计与扣费由服务器决定；动画不会重复扣费。报幕、暂停、隐藏、断线和换节目会清理过期动效。
- 弹幕在上方三分之一四轨展示；短时报幕提示占用区域时，最多暂存 4 条，提示收起后展示。颁奖和片尾不叠加飞行弹幕。

## 晚会结束

主持宣布结束后，确认“结束晚会”。服务器立即锁定只读，大屏直接显示无按钮的“感谢你的参与”。完整 165 秒片尾（6 秒序幕、135 秒节目致谢、18 秒结语、6 秒定格）只在主持预览与后台纪念页使用。没有协同点亮按钮和人数进度要求。

手机进入个人纪念页。刷新、断线重连、隐藏恢复及减少动态效果直接显示终章定格，不强制重播。节目与互动回顾通过主动入口查看。排练预览保留在独立排练场次。

## 暂停与恢复

暂停后先核对连接、当前节目和当前互动；恢复时只呈现当前状态，不补播旧礼物。若已结束锁定，不再恢复互动。

代码和数据配置必须配套：D-110 使用 schema 24；恢复到 D-109 时配套使用 schema 23 正式库。先保留新库和新记录，再切回旧代码与旧配置，禁止让 D-109 直接读取 schema 24。


## 半屏控台功能位置

将网页和 OBS 各放半屏。主验收视口为 960×900，紧凑视口为 800×700；页面本身不向下滚动，名单在页内翻页。准备节目不代表已经执行，当前环节栏以服务器确认结果为准。

| 位置 | 保留的功能 |
| --- | --- |
| 顶部 | 连接、模式、轮次、开始、全场暂停／恢复 |
| 固定按钮 | 非互动页保留报幕／主题背景、返回节目、执行选中项、下一项、结束晚会；互动页集中在互动主控面板 |
| 节目页 | 25 项分页、选择待执行、载入预设、编辑与导入目录；编辑弹窗按钮固定 |
| 互动页 | A 布置 `mix`、10 秒自动抢答、判错续播、关闭；B 设置选手和投票、关闭揭晓、收起结果；C 仅线下说明 |
| 颁奖页 | 节目动力调整与前三名、校园奖草稿编辑与确认、展示、揭晓及翻页 |
| 弹幕页 | 暂停、恢复、删除、屏蔽来源及清屏，列表分页 |
| 管理页 | 学生／工作人员／游客人数、就绪提醒、归档记录；排练模式含场景与片尾预览 |
| 底部 | 操作结果、异常提示、归档并重置本轮 |

## 归档并重置本轮

1. 只有主控管理账号可以执行。运行中先点“全场暂停”，或等到场次已结束。
2. 点底部“归档并重置本轮”，核对影响范围并输入 **重新开场**。
3. 服务器先创建并验证受保护的数据库归档。失败保留原轮次，不进入新一轮。
4. 成功后核对轮次加一、状态为待开始，校园奖回到未确认草稿，全部人员重新核验与选色；游客名额释放。学生名单、工作口令、节目目录及校园奖内容保留。
5. 手机自动返回一屏入场表单；已结束纪念页同样监听新轮次。旧请求不会写入新轮次，网络响应丢失时原请求重试返回原结果。

正式重置会清除当前轮次状态，不能拿它代替“恢复运行”。数据归档不通过网页公开下载。服务器恢复步骤见版本发布恢复索引。

## 入场与末段顺序

学生和工作人员一屏填写姓名、8 位学号、星色；游客填写昵称与星色。初次成功后手机播放一次约 1.6 秒个人星色流星，刷新不重播；大屏开场显示当前已入场人数，并在新入场事件到达时显示一次短流星，不恢复银河背景，也不显示全场入场星海。第一次执行节目后人数和入场流星均隐藏。工作人员和游客均初始 100 动力，可发弹幕、送礼，不参与正式计分或投票、抢答。游客转学生通过“核验学生身份”，两份余额及记录不合并。

末段按 **互动三 → 节目颁奖（约 5 分钟）→ 光年之外／查无此队 → 负责人讲话（约 8 分钟）→ 校园图鉴颁奖（约 15 分钟）→ 主持结束语 → 感谢你的参与** 执行。时长只作提示，网页和 OBS 都由操作员按口令推进。
# D120 现场顺序与颁奖补充

“下一项”由服务端按照节目目录相邻顺序推进，不能用后台下拉框绕过顺序。互动、投票和颁奖尚未收尾时，服务端会拒绝推进；需要临时跳转时才使用“执行选中项”。节目颁奖位于互动三之后，随后是《光年之外》、负责人讲话和校园图鉴颁奖。

校园图鉴名单来自 `backend/data/campus-awards-20260917.json`，发布前通过 `pnpm db:campus-awards:import` 导入并保持已确认。颁奖顺序为路线三等奖、路线二等奖、路线一等奖、摄影/创意组合页、积分前 20；大屏选择摄影奖时会同时展示摄影和创意两个独立奖项的姓名，备注不会发送到公共屏幕。

开始活动只结束入场阶段：人数和新流星隐藏，中央星芒闪烁约 800ms 后停留在 HOST 报幕背景，第一项节目仍需主控点击执行。负责人讲话网页只显示报幕背景，孙晟博、罗慧婷头像及姓名由 OBS 现场图层放置。
