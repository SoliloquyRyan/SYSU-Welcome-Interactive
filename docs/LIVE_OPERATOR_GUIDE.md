# 迎新晚会主控操作单 · D-109

本页适用于 D-109 / schema 23。主持台词与计时见[主持人动画对稿单](./HOST_CUE_GUIDE.md)，实施、实测和恢复索引见 [D-109](./D109_IMPLEMENTATION.md)。D-108 代码与 schema 22 正式库独立保留；发布不自动重置已结束场次。

## 开场前

1. 检查手机、大屏和控台使用同一发布版本。控台显示实时已连接，核对实际模式、状态、轮次、25 项目录和 19 个表演节目。已结束的旧轮次需要主控明确归档并重置，才会回到待开始。
2. NFC 全部写入统一手机网址。学生姓名与 8 位学号必须匹配正式名单；工作人员按分发指引在相同姓名、学号字段填写账号信息；游客使用“游客参与”，每轮最多 94 人。不要把主控口令交给应援人员。
3. 核对六类校园奖项草稿：15、5、10、3、3、20 人；摄影三人均颁奖。确认草稿不等于揭晓，公开画面以逐项揭晓为准。
4. 在 OBS 核对原视频、伴奏和现场音源。网页负责背景、标题与互动；OBS 播放、停止和切场由操作员执行。先用独立排练配置验证，不在正式库中制造测试送礼或投票。
5. 确认学院标志、标题和姓名在 LED 上可读。微信、音频调音台与 LED 的实体联排另行记录。

## 开始与报幕

- 选择正式模式并开始活动，停在星海集结。锁色后计入已入场人数，断线不会减人。
- 主持口令后推进节目阶段，大屏 12 秒开场，手机 2.4 秒过渡；业务状态即时更新。
- 每次报幕点“报幕／主题背景”，显示 2026迎新晚会及主题副标题，暂停送礼。
- 浏览节目或编辑候选只做准备；必须明确点“执行选中项”或“返回节目”才执行现场切换。

## 互动与颁奖

| 环节 | 执行动作 | 收尾 |
| --- | --- | --- |
| 互动一 | 填写提示，开始抢答；等待三秒倒计时和首个有效响应 | 收起本轮互动，再继续 |
| 互动二 | 设置 2～12 位选手标签与题目，确认选手并开放投票。候选无需观众账号，投票时不可修改 | 关闭投票并确认揭晓；随后收起结果，或使用收起互动并进入下一项 |
| 互动三 | 执行线下互动背景，主持人组织现场活动 | 选择下一节目并明确执行；不开放抢答 |
| 节目颁奖 | 核对正式动力前三名；并列时按现场确定的结果调整并留下记录 | 确认揭晓；工作人员、游客应援不计入排名 |
| 校园颁奖 | 核对并确认草稿，选择当前奖项，再确认揭晓 | 每页念完再翻页；修改已公开名单前先收起 |

组合操作按顺序完成，前一步成功并取得最新状态才执行下一步。中途失败会停止并显示已完成步骤；先核对控台状态，再从尚未完成的步骤继续，避免重复执行。

《光年之外》为查无此队，保留完整六位成员介绍，继续禁礼物。讲话使用独立标题。

## 音乐、弹幕与礼物

- 本机 `pnpm obs:audio --check` 只读检查已映射音源，`pnpm obs:audio` 启动音乐动效。只读取音量，不自动调音量或播放媒体。
- 现场调音台和乐器必须明确配置到节目映射的 `liveInputs`；主持话筒、桌面声音不自动纳入。
- 节目与报幕中的观众星平时透明，确认礼物后局部短闪。音乐只影响薄雾、微尘、轮廓光；手机不会接收音频数据。
- 四档礼物有界合并，统计与扣费由服务器决定；动画不会重复扣费。报幕、暂停、隐藏、断线和换节目会清理过期动效。
- 弹幕在上方三分之一四轨展示；短时报幕提示占用区域时，最多暂存 4 条，提示收起后展示。颁奖和片尾不叠加飞行弹幕。

## 晚会结束

主持宣布结束后，确认“结束并播放片尾”。服务器立即锁定只读，片尾约 165 秒：6 秒序幕、135 秒节目致谢、18 秒结语、6 秒定格。没有协同点亮按钮和人数进度要求。

手机进入个人纪念页。刷新、断线重连、隐藏恢复及减少动态效果直接显示终章定格，不强制重播。节目与互动回顾通过主动入口查看。排练预览保留在独立排练场次。

## 暂停与恢复

暂停后先核对连接、当前节目和当前互动；恢复时只呈现当前状态，不补播旧礼物。若已结束锁定，不再恢复互动。

代码和数据配置必须配套：D-109 使用 schema 23 正式库；恢复到 D-108 时配套使用升级前的 schema 22 正式库。先保留新库和新记录，再切回旧代码与旧配置，禁止让 D-108 直接读取 schema 23。


## 半屏控台功能位置

将网页和 OBS 各放半屏。主验收视口为 960×900，紧凑视口为 800×700；页面本身不向下滚动，名单在页内翻页。准备节目不代表已经执行，当前环节栏以服务器确认结果为准。

| 位置 | 保留的功能 |
| --- | --- |
| 顶部 | 连接、模式、轮次、开始、全场暂停／恢复、进入节目 |
| 固定按钮 | 报幕／主题背景、返回节目、执行选中项、下一项、结束并播放片尾 |
| 节目页 | 25 项分页、选择待执行、载入预设、编辑与导入目录；编辑弹窗按钮固定 |
| 互动页 | A 抢答、B 设置选手和投票、关闭揭晓、收起结果；C 仅线下说明 |
| 颁奖页 | 节目动力调整与前三名、校园奖草稿编辑与确认、展示、揭晓及翻页 |
| 弹幕页 | 暂停、恢复、删除、屏蔽来源及清屏，列表分页 |
| 管理页 | 学生／工作人员／游客人数、就绪提醒、归档记录；排练模式含场景与片尾预览 |
| 底部 | 操作结果、异常提示、归档并重置本轮 |

## 归档并重置本轮

1. 只有主控管理账号可以执行。运行中先点“全场暂停”，或等到场次已结束。
2. 点底部“归档并重置本轮”，核对影响范围并输入 **重新开场**。
3. 服务器先创建并验证受保护的数据库归档。失败保留原轮次，不进入新一轮。
4. 成功后核对轮次加一、状态为待开始，校园奖回到未确认草稿，全部人员重新核验与选色；游客名额释放。学生名单、工作口令、节目目录及校园奖内容保留。
5. 手机自动返回一屏入场表单；已结束纪念页同样监听新轮次。旧请求不会写入新轮次，网络响应丢失时原请求重试返回原结果。

正式重置会清除当前轮次状态，不能拿它代替“恢复运行”。数据归档不通过网页公开下载。服务器恢复步骤见版本发布恢复索引。

## 入场与末段顺序

学生和工作人员一屏填写姓名、8 位学号、星色；游客填写昵称与星色。初次成功后手机播放一次约 1.6 秒个人星色流星，刷新不重播；大屏星海集结保持。工作人员和游客均初始 100 动力，可发弹幕、送礼，不参与正式计分或投票、抢答。游客转学生通过“核验学生身份”，两份余额及记录不合并。

末段按 **互动三 → 节目颁奖（约 5 分钟）→ 光年之外／查无此队 → 负责人讲话（约 8 分钟）→ 校园图鉴颁奖（约 15 分钟）→ 主持结束语 → 电影片尾** 执行。时长只作提示，网页和 OBS 都由操作员按口令推进。
