# 手机端动画协作交接

> 日期：2026-08-14
> 工作基线：`feature/mobile-interaction-layout`
> 当前权威：D-025、D-026、D-027、D-028、D-029 与 [PROTOCOL_V2.md](./PROTOCOL_V2.md)
> 范围：`/welcome` 的身份激活动线、星系主场景、底部操作坞与手机端动效；业务事实仍由服务端决定

## 一键进入

Windows 下直接双击仓库根目录的 `打开手机端预览.cmd`。该入口会自动进入仓库、查找系统或 Codex 自带的 `pnpm`，并仅在首次缺少依赖时执行冻结锁文件安装。启动后会打开 390×844 的真实 v2 手机页和手机动线检查器；控制上下文中的 v2 后台负责节目选择、暂停/恢复与全场推进。检查器把“个人入场”和“现场场景”分区，可依次查看星色、锁色入公共星系、胶囊提交/跳过、等待启程、三个场景、权威终章与刷新恢复，所有节点都通过真实接口进入，不会向正式页面加入调试入口。

预览使用 OS 临时目录中的固定合成目录并执行受控 v2 切换，启动真实 HTTP/WebSocket 与 Vue 页面；不读取或修改 `backend/.data/`。它可作为 V2-08 的桌面手机视口协作与回归入口；V2-10 的 30 分钟自动渲染 soak 已通过，但该预览与自动长跑都不替代 vivo X300、三端局域网或 OBS 实际合成人工签收。

如需使用终端，也可以在仓库根目录执行：

```bash
pnpm install --frozen-lockfile
pnpm preview:mobile
```

第二条命令会启动隔离的临时 v2 后端与真实前端，自动打开 `390×844` 手机端和桌面动线检查器；控制上下文使用只存在于进程内存的合成后台凭据登录。保存前端 Vue、CSS 或 JS 后，手机窗口会由 Vite HMR 自动更新。锁色、胶囊决定和场景动作都是真实临时数据写入，所以重看首次流程需关闭并重新启动预览；关闭手机端窗口或按 `Ctrl+C` 会关闭全部窗口、删除临时数据库/备份并释放端口。

该入口不读取 `backend/.data/`，不输出邀请令牌、合成姓名、Demo 码或后台密码，也不会建立正式业务后门。

## D-025 / D-027 / D-028 手机端交接实现

- NFC 或备用核验成功即完成身份激活并进入选色；星色锁定的服务端事务会原子写入色温、稳定槽位并让个人恒星加入公共星系。客户端只有在权威响应/快照确认包含本人恒星后，才显示它并播放点亮拉远。
- 星色锁定成功时参与者权威状态已经是 `NEEDS_CAPSULE_DECISION`，客户端随后呈现档案提交/跳过决策；动画完成、失败、超时或静态降级都不能推进、延迟或阻断该状态。提交档案或明确跳过后进入服务端当前场景。晚到者遵循同一顺序，不从动画或本地时间推断现场阶段。
- 主页面是持续流动但可静态降级的真实星系：最多 300 颗真实恒星，自己的星下面显示公开编号并突出，其他恒星不显示标签；稳定位置来自服务端，动画只做插值。
- 下半页只保留一个克制的液态玻璃操作坞，承载当前场景的主操作。不能堆叠玻璃卡片墙，不能循环动画 `filter`、模糊或大阴影；不支持时使用高对比不透明面板。
- D-027 把正常首次寻星修订为约 2.8 秒并冻结稳定 `visible` 后开播；D-028 在项目负责人真机否决首版视觉连续性后，把当前镜头统一为一颗从电影持续到选色静态态的恒星节点、横向 `50%`/纵向 `42vh` 的同一视觉轴，以及“建立/加速 → 连续穿越 → 减速/捕获 → 锁定/交接”四阶段。背景使用全屏低 DOM SVG 径向速度线，恒星使用同心白核、中性光晕与默认 `5800K` 色温光晕；权威星色锁定和快照到达后仍播放约 1.2 秒“点亮自己的恒星并拉远到星系”。正常首次流程不提供跳过按钮。
- D-029 替代上一条中“锁色后立即拉远”的顺序：锁色后同一持久星约 1.2 秒闪烁并上移到寄语画面；提交或持久化跳过胶囊且 `ADMITTED` 已由服务端确认后，再以约 3.2 秒缩远到 Canvas 本人轨道。低亮轨道微尘只增强低人数时的环绕层次，不代表参与人数；本人真实星仅轻微放大并保留标签。
- 选色文案与控件在寻星期间提前渲染，但必须保持 `inert`、不可聚焦；主动画 `animationend` 到达时只解除交互隔离，不替换恒星节点或改变中心、尺寸、颜色与布局，定时器只作事件缺失时的兜底。
- 开播前页面暂不可见时应等待；镜头真正开始后若页面进入后台或被中断，立即收束到权威静态终态且返回不重播。返回、刷新、断线恢复、失败、超时和 `prefers-reduced-motion: reduce` 也直接显示静态终态与可用操作。
- 普通成功提示显示约 3.5 秒后收回，并由页面内持久权威状态接替；错误、离线、暂停和已结束提示保持显示，直到状态改变或用户处理。
- 退出每次都确认。未提交草稿只保存在当前内存；完成、退出和会话重置时清除，弹幕草稿还要在离开节目互动场景时清除。
- 正常页面删除“实时同步”、裸露的 `RUNNING`、六阶段编号和常驻身份/数值行；异常状态仍以文字说明，不能只靠颜色或动效。
- 手机端继续使用现有 Vue 架构：D-028 首次叙事镜头只用 Vue+CSS+低 DOM SVG，Canvas 只负责权威星系；D-026 仍只为 V2-07 `/screen` 批准按需加载 GSAP core，不批准插件、Three.js、逐星 GSAP 或把大屏时间线直接搬到手机端。
- 2026-08-14 的可靠性加固让所有文本输入共享视觉视口/键盘布局，补齐触控与弹窗语义；实时双流只有追平权威高水位后才开放写入，旧代际快照、命令和动画不能在退出后恢复身份，弱网快照同时保留主动取消与 15 秒超时。胶囊冲突、礼物离线/暂停、超过 300 星和协议不兼容均以可见、失败关闭方式处理。
- D-027 自动证据缺口已关闭：新鲜邀请、normal-motion、生产 Vue 页面与隔离 v2 smoke 的聚焦浏览器回归曾真实通过；根级复跑观测正常首次 `2854ms`、隐藏→可见后 `2756ms`，隐藏期间不播放也不选色，开播后进入后台在 `<600ms` 内静态且不重播。这些历史证据只证明几何、时长、可见性、恢复和业务隔离，不证明视觉连续性；项目负责人真机已否决首版视觉。
- D-028 当前自动连续性子门已通过：Chrome artifact 正常首次 `2783ms`、隐藏→可见 `2717ms`，F6→F7 同一恒星节点中心/尺寸差 `0px`、CLS `0`，六帧序列已目检；全量 37 文件/341 条测试、`typecheck`、`typecheck:e2e`、前端 71 模块构建、三项目 v2 E2E（退出码 0）与现场预览 smoke 均为 `PASS`。仍须 vivo X300 使用当前版本的新鲜邀请进行人工视觉签核。

## V2-07 大屏动画交接（已实现）

- 公共星系使用单 Canvas，最多 300 颗权威恒星；稳定槽位决定坐标，大屏不绘制编号，不为单星建立 DOM/焦点节点。Canvas 在普通全屏场景最多 30fps、DPR 封顶 2，标签页隐藏或节目透明叠加时停止持续帧循环。
- GSAP 通过动态 import 成为独立 chunk，只编排场景标题、匿名弹幕、有限礼物与 LIVE 终章；动画实例按组件作用域追踪并在插播、卸载或高优先级状态到来时逐一 kill，不使用全局 `killTweensOf('*')`。
- `PROGRAM_SUPPORT` 不承载节目视频：网页背景透明、中心清空，OBS/导播负责媒体和声音。实时弹幕只做有限车道横移，礼物同时最多主/次两个，同类 1.5 秒合并；胶囊插入时不排队、清除后不补播。
- LIVE 终章从实时未完成态进入 `COMPLETED` 时播放约 5～6 秒；初始已完成快照、刷新、重连和 reduced-motion 直接显示稳定终态。排练终章始终保留可见预览标记。
- 动画失败或 GSAP chunk 加载失败时，Canvas、场景文案、快照弹幕、胶囊和终态仍完整可读；任何 animation complete 都不得调用运行命令、写积分或推进 presentation。
