## 2. 安全启动

1. 确认电脑与 vivo X300 连接同一可信私网，关闭 VPN/代理，确认没有真实参与者数据。
2. 在 PowerShell 中只设置本机当前可信 IPv4：

   ```powershell
   $env:DEMO_HOST = '192.168.x.x'
   pnpm preview:v2:field
   ```

3. 启动器必须拒绝公网、虚拟接口和 `0.0.0.0`，不得自动修改防火墙；如系统请求放行，只允许当前可信专用网络。
4. 终端应显示统一入口与 OBS `/screen` 地址；电脑浏览器应自动打开已登录后台、大屏和专用“手机验收二维码”页。二维码页只显示一次性合成手机入口与扫码说明，终端不可见也不影响扫码；任何界面都不得显示邀请令牌文本、姓名、学号或后台密码。
5. 手机扫描二维码后，地址栏中的 token 必须立即被清除。按 `Ctrl+C` 或关闭预览浏览器后，临时数据库和端口必须清理；实际 `backend/.data/` 不得发生变化。
6. 验 normal-motion 首次镜头前关闭系统“减少动态效果”，确认浏览器报告 `prefers-reduced-motion: no-preference`，使用本次新启动临时栈的新鲜邀请和无既有会话的浏览器上下文；扫码后保持页面前台可见，不能用已经激活的同一身份复验首次镜头。
