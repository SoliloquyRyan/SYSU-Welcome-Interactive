# D-106：留白观众星、方线体与手机送礼闪星

状态：本地实现及以下验证完成，视觉可审阅；未发布、未提交。

## 本轮变化

- 使用负责人提供的 `FZZH-FangXTJ-L.TTF` 制作本地标题 WOFF2 子集；大屏中文几何标题接入 Fangxian，英文 Orbitron、微复古宋体和手机 / 姓名 Noto 延续。
- 大屏节目主标题与表演者放大，视频短时报幕同样提高字号；长标题及长名单使用独立尺寸约束。
- 十张完整背景逐张记录天空 / 薄雾多边形；按 `background-size: cover` 的实际裁切投影，避开建筑、桥梁、窗框及文字。星位由稳定编号决定，与在线连接数和列表顺序无关。
- 视频层的观众星分布扩展至全屏，平时透明度约 2.5%；高亮礼物独立避开人物、字幕与学院标志。每批礼物最多点亮四颗邻近真实星，结束后退回淡显。
- 手机开放中部留白中的星空，增加星光明暗层次、少量短星芒和柔散微尘；对应礼物星点闪亮，输入、星色选择和礼物面板保留。星点仍只来自已入场公共列表，0 人不造星。
- 微光 / 信标的 SVG 与背景星光共用渲染器输出的实际投影点，横竖屏裁切或尺寸改变后锚点保持对齐。星轨、小星舰沿用 D-105 路径和有界队列。

礼物闪亮锚点由事件 ID 在可见真实星中稳定选择；当前公共礼物消息只有星色，没有发送者星号，因此这些光效不表示已确认的发送者身份。
