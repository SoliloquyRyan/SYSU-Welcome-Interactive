# D-076 原版构图与流动星云修订

状态：2026-09-08，本地实现与审片。负责人在对照 D-071 / D-062 与 D-075 后，确认以原版倾斜盘面为基础，先确定背景、再添加流动星云，并按同一流向布置星体。本轮未发布服务器；既有发布记录见 D-075。

## 当前实现

- 背景回归有留白的深墨蓝空间；银蓝旋臂、局部暖白核心与清楚星体分层绘制。原版大屏左下标题构图恢复，右上仍使用真实已入场人数。
- 新增共享 `stellar-flow.js`：稳定 formationSlot 决定星位，星云和星体使用同一旋臂曲率、260 秒整体流动周期及有界差速。相机缓慢侧移，两端分别取景；手机个人星与拖尾使用同一投影，星号紧随星体。
- 新增原生 WebGL2 `stellar-nebula.js`：五层薄星云、扰动纹理与暗带形成厚度；核心与较宽的柔光分开。大屏最长边最高 1920，手机背景最高 1000，清楚星核仍在可见 Canvas 的分辨率上绘制。没有增加依赖或外部图像请求。
- 普通手机轨道绘制目标 30Hz，首次旅程保留 5.4s / 1.0s / 4.2s。开场继续为 12 秒，镜头、星云和星体连续汇聚后交接；星舰维持现行 5.8s / 7.2s。
- Canvas2D 回退使用缓存材质和透视网格，沿相同世界路径移动。修复普通节目在静态 / WebGL 回退时漏画实时星体的问题。OBS `media=overlay` 的节目终点继续精确透明。
- 本地审片支持手机 / 大屏、30 秒流动样片、暂停 / 继续、星舰和开场，以及背景 / 星云 / 完整画面分层查看。样片人数与消息全部为合成样例，无数据库连接。

## 业务与边界

本次只修改呈现。服务器 epoch、节目编排、真实人数语义、星号、选色、礼物价格与账本、审核、抽奖结果和协同统计均未改动。手机不增加全场星位订阅；局部装饰星密度继续与到场人数无关。真实星仍由稳定槽位承载，人数变化与快照重排不重排已有星。

减少动态为静态终态；隐藏时停止动画，导航卸载清理帧循环与 GPU 资源。审片的暂停功能冻结当前手机画面，并在恢复时扣除暂停时长；它不是活动暂停指令。
