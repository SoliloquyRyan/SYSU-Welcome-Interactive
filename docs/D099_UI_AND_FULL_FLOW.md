## 已发现与实施记录

1. 手机端：统一登录、选色、礼物和纪念卡的圆角与半透明层次；礼物选中勾记与发送总额更明确。补充聊天空态与未选色档案状态。高级弹幕确认收起底层选色、首焦点落在返回，支持Tab循环、Escape和焦点恢复；有效正文进入确认后清掉旧输入错误。离开节目场景时同步撤下未发送的高级确认框。
2. 主控端：登录错误移出登录后分支，节目编排前置，准备统计、回执和维护操作折叠；调分表单位于列表上方。动作按钮与角色/阶段权限一致，360/390窄屏可达。
3. 共用确认与大屏设置：统一玻璃面板、20px外圆角和12px控件圆角；约束窄屏宽度、最大高度与内部滚动，保留返回/确定。
4. 谢幕：去掉弹幕列表双份复制和固定24秒截断，按实际宽度以120px/s完整滚动一遍后结束；手动/减少动态回顾采用可滚动双列。完成后撤下/屏蔽/清屏立即反映到已打开回顾；公开快照仅展示PUBLISHED，真实发送总数与原始账目保留。清屏后空态不再声称无人发送。
5. 未改动或绑定未确认的媒体；没有新增依赖、数据迁移、提交、推送或生产部署。schema保持21。
