# D120 晚会顺序、颁奖分页与开场视觉修正

## 已落地

- `ADVANCE_PROGRAM` 由服务端依据 `sort_order` 计算相邻节目；后台“下一项”不再提交浏览器选中的节目 ID。当前互动未收尾、版本过期或到达目录末尾时拒绝执行。
- 目录尾段固定为：互动三 → 节目颁奖 → 光年之外 → 负责人讲话 → 校园图鉴颁奖。
- 摄影奖和创意奖继续独立保存；选择摄影奖时公共舞台和后台以组合面板同页展示两个奖项的姓名。公共数据继续清空 `detail`。
- 校园图鉴颁奖顺序固定为：路线三等奖 → 路线二等奖 → 路线一等奖 → 最佳摄影/最佳创意组合页 → 打卡积分前 20 名。
- 正式校园图鉴名单源文件为 `backend/data/campus-awards-20260917.json`，六类名单使用 `pnpm db:campus-awards:import` 导入并直接标记为已确认。导入命令只接受明确的数据库路径、源文件和确认词。
- 正式轮次重置只清理节目奖动态状态，保留校园图鉴名单和确认状态。
- 开始活动后，大屏关闭到场人数和入场流星，播放一次约 800ms 的中央星芒闪烁，然后停留在 HOST 报幕背景；第一项节目等待主控执行。
- 负责人讲话网页只保留报幕标题和背景；孙晟博、罗慧婷两张头像及姓名由 OBS 现场图层自行放置。

## 现场顺序

1. 入场阶段观察迎新画面、人数和新入场流星。
2. 点击“开始活动”，确认人数和流星消失、星芒闪烁后停在报幕背景。
3. 主持人完成报幕后点击“执行选中项”；节目结束后使用“下一项”。
4. 互动、投票和颁奖必须先完成当前操作，再进入下一项。
5. 校园图鉴颁奖依次选择路线三等奖、路线二等奖、路线一等奖、最佳摄影奖 + 最佳创意奖 · 同页、积分前 20；摄影/创意揭晓后同页显示六名姓名，路线奖和积分前 20 仍按姓名长度分页。

## 数据导入

正式库切换前先完成正式数据库备份并停止服务，再执行：

```powershell
pnpm db:campus-awards:import -- --database <正式库绝对路径> --source backend/data/campus-awards-20260917.json --confirm CAMPUS_AWARDS_IMPORT
```

导入脚本会校验六类奖项均存在、人数大于零且 `confirmed=1`，不会读取或写入账号、班级、作品说明等身份信息。
