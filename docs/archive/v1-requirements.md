# v1 六阶段历史需求（归档）

> 来源：`docs/REQUIREMENTS.md` 2026-08-13 版本的 v1 部分。协议 v2（D-025）生效后，本节条款不再是实现或验收依据，仅保留编号与关键数字供追溯。现行需求见 [`../REQUIREMENTS.md`](../REQUIREMENTS.md)，权威契约见 [`../PROTOCOL_V2.md`](../PROTOCOL_V2.md)。

## 1. 流程（REQ-FLOW-1xx，六阶段）

- 101 有效个性入口直接建立参与者流程并显示编号星辰；备用入口才显示姓名/学号核验表单。
- 102 首次有效激活只创建一个参与者状态，发放一次 100 动力值和 20 星光值。
- 103 后台查看登录成功率、无效入口数和当前在线人数；大屏只显示匿名汇总。
- 104 参与者通过连续恒星温度条预览红—橙—黄—白—蓝白色域，显示 Kelvin 数值并提供无障碍数值说明。
- 105 点击"确认星色 · 进入星辰"后服务端保存并锁定色温；刷新、重连和多设备一致，本场不可修改。
- 201 星色确认后优先进入时光胶囊页；可跳过或提交最多 80 个可见字符。
- 202 提交前必须明确说明"内容可能经筛选后，以星号和星色在现场大屏展示"并主动确认。
- 203 提交即进入人工候选池，不存在"已填写但不入池"；候选不保证上屏，不由规则或 AI 自动公开。
- 204 首次成功提交奖励 20 星光；修改不重复得分，候选池保留最新权威正文。
- 205（FORMAL-PENDING）正式保存期限、撤回/删除、录像/直播提示与长期授权。
- 301 每个已激活参与者生成一颗稳定个人星星和唯一公开星号（姓氏拼音首字母 + 学号后四位，如 `L-4821`）。
- 302 后台推进到第 3 阶段后参与者可启动星星一次；大屏按已创建/已启动数量生成集结效果。
- 303 装饰动画失败时保留静态星点、数量和完成状态。
- 304 星星位置、尺寸由稳定种子派生；颜色由锁定色温决定；首次启动奖励 20 星光。
- 305（FORMAL-PENDING）正式汇聚图形、口令、音乐与灯光 Cue。
- 401 手机端显示当前节目、下一节目与开放状态；只有开放中的节目接收动力值。
- 402 动力值由服务端校验并幂等扣减，余额不得为负。
- 403 首次公开弹幕前显示一次性公开告知；经本地确定性规则后立即匿名上屏，无人工预审。
- 404 大屏不展示个人动力排行，只展示节目/集体维度聚合。
- 405 礼物四档：微光 5、信标 10、星轨 20、星舰 50；可重复赠送，不涉及金钱。
- 406 送礼单事务扣动力 + 写礼物事实 + 加热度；余额不为负；重试只生效一次。
- 407 首次送礼奖 10 星光；首次合规弹幕奖 10 星光；下屏不追回。
- 501 第 5 阶段"全场协同点亮"；每人最多成功一次，首次奖 20 星光。
- 502 星光只记录参与成长，不兑换、不转赠、不补充动力。
- 503 大屏显示点亮人数、有效参与人数和百分比，不公开个人排名。
- 504 重复点击、刷新、并发和重试不得重复点亮或得分。
- 601 结尾大屏展示集体星图、激活数、星光总量、互动次数、等级分布和仍被人工选中的胶囊；未选中正文不得出现。
- 602 集体画面不含完整姓名、完整学号、入口令牌或身份映射。
- 603 个人档案只向本人展示：星号、星色、互动次数、双值和本人胶囊。
- 604 完成后已有参与者可重新核验查看档案；未激活令牌不得再创建新参与者。
- 605（FORMAL-PENDING）正式档案开放期限不超过活动后 30 天。

## 2. 双值与公共内容（v1）

- 动力值初始 100，用于节目应援，用完不自动恢复；星光上限 100，分配为激活 20 / 私密寄语 20 / 星星启动 20 / 首次送礼 10 / 首次合规弹幕 10 / 协同点亮 20。
- 双值界面使用不同名称、图标、颜色和说明；所有扣减与奖励具备数据库唯一约束及幂等保护。
- 弹幕状态 `PUBLISHED / REJECTED_BY_RULE / REMOVED`；无 `PENDING/APPROVED` 人工预审。
- 本地规则拒绝敏感词、链接、联系方式、超长或超频内容；拒绝给出可修正原因，不广播不奖励。
- 后台支持删除单条、屏蔽匿名来源、暂停新弹幕、紧急清屏；下屏内容重连后不得恢复。
- 胶囊候选列表默认只显示星号、星色和正文；AI 审核只保留可替换接口。

## 3. 后台与大屏（v1）

- 后台单页管理运行模式、六阶段、固定节目、弹幕、参与者与入口统计、在线情况、异常状态和确定性重置。
- 共用一个登录账号；任何已登录会话可自提 `REVIEWER / STAGE_CONTROLLER / DEMO_ADMIN / ALL`；服务端仍校验命令所需角色。
- 运行状态 `mode=REHEARSAL|LIVE`、`status=READY|RUNNING|PAUSED|COMPLETED`、`stage=1..6`；排练可跳阶段，现场只向前。
- 模式切换、现场推进、结束、令牌操作、重置和紧急清屏用确认对话框；暂停互动立即生效。
- 大屏只消费聚合数据、公开星号/星色、`PUBLISHED` 弹幕和人工选中胶囊。
- 大屏断线自动重连并拉取最新快照；1920×1080、浏览器缩放 100% 为 Demo v0 大屏基线。

## 4. 非功能（v1）

- 300 合成参与者协议级负载（G4 专项）：301 条 WebSocket、300 次激活、1200 次礼物、300 次弹幕、300 次协同点亮；阶段/礼物/弹幕/点亮传播 p95 ≤ 2s。
- 幂等、频率限制与服务端校验覆盖登录、扣减、得分与提交内容。
- G3 覆盖 Windows Chrome、Windows Edge、1920×1080、`prefers-reduced-motion` 与 vivo X300 人工旅程。
- 日志不得记录真实姓名、完整学号、完整令牌、Cookie、后台密码、胶囊正文或完整弹幕正文。
- 断线阻止业务写入、不在客户端排队；重连先拉权威快照；刷新和服务重启不丢已提交状态。
- 确定性重置恢复相同合成身份、学号摘要、星号、令牌、节目和礼物，并递增 `resetEpoch`。
- 动画使用 CSS、SVG 或 Canvas，不安装大型动画或 3D 库；reduced-motion 直接静态终态。
- 根级一条命令启动本地服务与三端网页，输出手机 URL、二维码、后台 URL、大屏 URL 与共用账号提示。
- 约 390×844 时 `/welcome` 文档不得纵向滚动；主导航"星程 / 节目单 / 档案"；触控目标 ≥ 44×44px。
- 入场动画约 1.8 秒、约 0.6 秒后可跳过；怀士堂使用原创简化几何轮廓（后来在 D-024/D-025 中取消）。

## 5. G3 最低验收场景（v1）

- 同令牌 NFC/二维码入口后账号、动力值、星光值和个人档案一致。
- 重复轻触、扫码、刷新、超时重试不重复注册、发分或扣分。
- 只有经人工选中的胶囊可上屏；未选中、已撤下或重置前正文不得显示或重连后恢复。
- 大屏断线重连恢复正确节目和聚合数据，不显示姓名、学号或入口令牌。
- 共用后台未登录不能读管理数据；登录后可自提权，日志不伪装个人归因。
- 排练可跳阶段，现场只向前；过期阶段命令被拒绝。
- 离线写入被阻止；重连、刷新和服务重启后状态一致。
- 确定性重置后旧二维码仍有效，旧会话必须重新核验。

> 完整原文与逐条验收状态以 Git 历史中的旧 `REQUIREMENTS.md` 为准。
