## 约 20 分钟跑完的顺序

D-066 大屏修复：更新后 `/screen` 默认完整动效，不再因 Windows 关闭动画而隐藏弹幕。临时用 `/screen?settings=1` 检查“完整动效 / 大屏实时已连接”，检查后隐藏设置。手机发送新弹幕必须处于“运行中 + 节目应援”、转场结束且没有抽奖/终章覆层；人数少不会阻止飘屏，刷新不补播旧消息。静态模式保留定时显示的正文。详细检查步骤见 [`RUNBOOK.md`](./RUNBOOK.md) §5.2；本轮覆盖与发布状态见 TEST_PLAN §3.28。

| 步骤 | 后台操作 | 手机和大屏应看到什么 |
|---|---|---|
| 1. 开演前 | 保持“待开始”，核对已应用的 21 项；为测试完整收尾先点“切换为现场”。只有目录被重置后，才需“载入本场节目单”并“确认应用 21 项” | 手机节目单是本场 18 个表演、3 个串场；不要在运行中重新导入目录 |
| 2. 扫码入场 | 让 3–5 人使用不同邀请进入，再点“开始活动” | 首次手机寻星后选色；锁色后大屏出现一次到场流星，刷新不补播 |
| 3. 集结 | 保持“01 星海集结”，让大家点“启动我的星” | 手机首次启动增加 40 星光；大屏银河流动，人数增加不重排原有星位 |
| 4. 正式节目 | 点击“推进下一场景”到“02 节目应援”，再点“开始首个节目” | 大屏约 8.4 秒汇聚、超新星、连续变透明；OBS 原有视频接管；手机显示 lovesik girls |
| 5. 应援与串场 | 在节目目录“下一项”或选择当前项；抽查第 7、14、20 项 | 表演可送礼并扣相应动力；串场禁送礼且不扣动力。合规新弹幕实时上屏，刷新不重放。第 20 项竞拍目前只占位 |
| 6. 抽奖 | 保持“运行中 + 节目应援”，点“开启抽奖大屏”，连续“抽取一位”两次，再关闭 | 结果按抽取顺序逐位揭晓，无重复；后台可看合成姓名，大屏只看公开星号；大屏刷新后恢复已抽结果 |
| 7. 异常操作 | 暂停再恢复；让一部手机短暂断网并回来 | 断网时提示且禁写，重连先恢复权威状态；不自动重交草稿。暂停会收起抽奖但保留记录 |
| 8. 协同点亮 | 把当前节目设到最后一项，再“推进下一场景” | 三端进入“03 协同点亮”；手机逐个参与，大屏人数、进度与集体亮度随之增加 |
| 9. 结束 | 确认人数和主持口令后点“结束并锁定终章” | 手机与大屏进入结束页，手机只读；有人未参与时在一次确认中提醒。当前是功能终章，电影回忆录美术尚待制作 |

排练模式用“02 节目应援”“03 协同点亮”直接切场，并通过“预览终章”查看结尾；要验证真正完成后的只读锁定，须在“待开始”时先切换为现场模式，再按表中顺序执行。

“下一项”只切换当前节目；“推进下一场景”会离开节目阶段进入协同。正式现场模式的场景不可回退，所以每个节目之间应使用“下一项”。节目时长只供主持与导播参考，系统不会自动切节目。

重复排练时只在本合成测试库中使用 Demo 重置；它会清除这轮测试产生的记录。需要保留的问题先记下复现步骤和发生时间，再由主控操作重置。正式名单和正式数据库不使用此入口。
