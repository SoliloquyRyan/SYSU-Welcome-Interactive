# D-111 实施记录

## 已落地

- `START` 在服务器确认后直接进入 `PROGRAM_SUPPORT` 和主持报幕状态；旧 `ASSEMBLY`、`START_STAR` 仅保留历史兼容。
- 公共大屏等待与旧星海集结画面不再绘制观众星和人数计数，主题标题为“2026迎新晚会／以星光作序，与未来相逢”。
- 互动 A/B/C 在空闲时分别显示“歌名 decoder”“谁是卧底”“谁是最‘人’”，互动 C 保持线下互动。
- `COMPLETED` 公共画面只显示“感谢你的参与”，片尾仍只在主持预览和后台排练入口使用。
- OBS 音频文件按完整 `B2/R2/R3_…_mix.mp3` 文件名匹配；Windows 路径统一处理，hint、answer、R5 和重复映射均不会触发自动抢答。桥接动作串行轮询，延迟事件不会绑定到下一题。

## 发布与恢复

发布包不包含名单、账号、口令、OBS 配置或音频；正式数据库需在服务器停止服务后按 D-111 发布脚本完成一致性备份、schema 24 升级和正式归档重置。D-109 的 release、schema 23 数据和 OBS 场景备份保留为回滚对。

## 尚需现场确认

真实 OBS 三组 mix 的播放、暂停、原位续播和自然结束保持抢答；1080p/60fps 30 分钟运行；微信真机、调音台和场馆 LED。未完成前不把“桥接可连接”表述为“现场联调通过”。
