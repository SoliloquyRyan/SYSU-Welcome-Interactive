## 音乐层及现场输入

OBS 已播出媒体 / 显式现场输入 → 本机桥接 → `sysu:audio-envelope` → 同一浏览器页面环境层。事件只含版本、归一化强度和可用状态；不把音频或输入名称传到业务服务或手机。文字与卡片保持稳定，手机不接收音乐强度。

采用 [OBS 音量事件](https://github.com/obsproject/obs-websocket/blob/master/docs/generated/protocol.md#inputvolumemeters) 与 [浏览器事件接口](https://github.com/obsproject/obs-browser#register-for-event-callbacks)。输出最多 20Hz，界面平滑插值；500ms 没有新输入后约 800ms 回落。暂停、隐藏、断线、换节目和转场重置；减少动态模式静态显示。

```powershell
pnpm obs:audio --list-inputs
pnpm obs:audio --check
pnpm obs:audio
```

前两项只读，不广播浏览器事件或控制媒体。映射可为每个节目增加 `liveInputs: ["调音台输入名称"]`；旧映射没有该字段时继续工作。只有当前播出场景内启用的媒体、明确指定的现场输入 / 全局音频输入，且未静音、路由到指定输出轨道、不是仅监听时才选用。多个输入取有界最大强度，不累加放大。桌面音频及主持话筒不自动纳入。桥接不自动播放、切场或调音。

当前正式场景集合没有配置现场调音台输入；软件受控音源验证与真实硬件接线验收分开记录。
