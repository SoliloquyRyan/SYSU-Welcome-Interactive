## 2. NFC 写卡与读取

### 2.1 应用和设备

- [ ] Android 主写卡机已安装官方 **NXP TagWriter**。
- [ ] Android 备用应用已安装 **NFC Tools by Wakdev**。
- [ ] 第二台手机作为验卡机，禁止和写卡机共用同一设备。
- [ ] Android 已开启 NFC、关闭省电限制并接入充电器/充电宝。
- [ ] 空白 NFC 标签为可写 NDEF 标签；未验证前不锁卡。

参考：

- NXP TagWriter 官方说明：<https://www.nxp.com/design/design-center/software/rfid-developer-resources/nfc-tagwriter-app-by-nxp%3ANFC-TAGWRITER>
- NFC Tools 官方 URL 写入说明：<https://www.wakdev.com/en/knowledge-base/how-to-guides/how-to-write-a-link-url-on-an-nfc-chip.html>

### 2.2 写入规则

所有标签只写同一个 URL，类型选择 `URL / URI`：

```text
https://sysuzgxytj.top/welcomeparty/welcome
```

不得写入姓名、学号、班级、工作口令、管理员账号、OBS 密码、桥接令牌或其他名单信息。

## 5. 互动一：真实 OBS 音频联调

```text
布置题目 → 选择 mix → 布置 10 秒自动抢答
→ OBS 播放 mix → 倒数 10 秒 → 抢答开放
→ 第一人抢答 → OBS 暂停 → 判错
→ 原位置续播 → 再次抢答 → 答对或主控关闭
```

- [ ] 未布置时普通节目音乐不触发。
- [ ] `hint`、`answer` 不触发。
- [ ] 倒计时期间抢答被拒绝。
- [ ] 第一位有效抢答后 OBS 音频暂停。
- [ ] 判错后从原位置续播。
- [ ] 同一人答错后可以再次抢答。
- [ ] 音频自然结束不会自动收题。
- [ ] 主控关闭本轮后旧事件不能重新打开。

## 8. 停止条件和签核

出现以下任一情况，立即停止写卡和现场推进，不自行重置：

- 手机空白或无法提交；
- 后台未连接；
- 大屏无法恢复主题；
- OBS 桥接不可用；
- 错误音频触发抢答；
- 抢答不能暂停/续播；
- 账号权限异常；
- 轮次、余额、名单或奖项出现非预期变化。
