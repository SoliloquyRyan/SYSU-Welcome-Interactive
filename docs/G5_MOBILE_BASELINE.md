> 适用范围：`/welcome` 手机端、身份入场、恒星/星系、时光胶囊决定及其与全场状态的接口边界
> 历史边界：D-022 继续冻结 G0～G4 的 v1 已验收实现；D-023/D-024 与当前 G5-01～G5-05 代码只作为 v1 历史基线，不能证明 v2 已完成

## 1. 当前权威与目标

D-025、D-027、D-028 与 [`PROTOCOL_V2.md`](./PROTOCOL_V2.md) 是当前权威。手机端不再把参与者的入场步骤和全场运行场景混成一条六阶段进度线，而是分成两条独立动线：

- **个人入场**：NFC/二维码核验并激活 → 选择并锁定星色 → 提交或跳过时光胶囊 → 已接入；
- **全场运行**：`ASSEMBLY` → `PROGRAM_SUPPORT` → `COOPERATIVE_LIGHT` → `COMPLETED` 终止状态。

`COMPLETED` 不是第四个场景，也不再存在第六阶段。档案是持续可访问的个人成长页；完成态只让它进入最终只读状态。

## 2. 个人入场状态机

| 权威状态 | 手机端体验 | 服务端事实 |
|---|---|---|
| 未核验 | NFC 为主入口，二维码/短网址为兼容备用 | 不创建参与者、不发放数值 |
| `NEEDS_COLOR` | 核验成功后进入星云/寻星，再选择恒星色温 | 首次激活一次；建立会话；发放 100 动力值与 20 星光 |
| `NEEDS_CAPSULE_DECISION` | 星色锁定后进入流动星系，再提交或跳过时光胶囊 | 色温不可变；本人恒星立即加入公开星系 |
| `ADMITTED` | 直接进入当前全场状态；档案可随时打开 | `SUBMITTED` 或 `SKIPPED` 已持久化；`admittedAt` 不再改变 |

- `READY` 与 `RUNNING` 允许首次入场和晚到者入场。
- 晚到者完成胶囊提交或跳过后直接进入当前场景，不补播已经错过的场景。
- `PAUSED` 期间允许读取与恢复，但拒绝激活、锁色、胶囊提交/跳过/补填等参与者写入。
- `COMPLETED` 后拒绝新参与者和所有参与者写入；已有参与者可重新核验并只读查看档案。
- 重复轻触、扫码、刷新、重试、多设备和并发不得重复激活、重复奖励、重复恒星或改变已锁定色温。
- 色温控件继续在红、橙、黄、白、蓝白恒星色域间连续变化，不插入绿色或紫色主色；界面显示 Kelvin 数值，屏幕阅读器获得控件名称、当前数值与范围。
- 拖动只做本地预览；必须由用户明确确认后才请求服务端锁色，锁定后本场不可修改。

## 3. 时光胶囊决定

- 胶囊正文仍以最多 80 个可见字符为当前基线。
- 提交前必须明确显示：`你写下的内容可能经筛选后，以星号和星色在现场大屏展示。`
- 胶囊决定持久化为 `SUBMITTED` 或 `SKIPPED`，两者都能完成入场。
- 首次实际提交奖励 20 星光；选择跳过当时奖励 0。
- 已跳过者可在 `READY` 或 `RUNNING` 从档案补填；首次成功补填仍只奖励一次，不改变 `admittedAt`。
- 一旦提交，正文进入人工候选池；用户不能选择“提交但不进入候选池”，候选也不保证上屏。
- 上屏只能由 REVIEWER 人工触发，作为不改变 `status/scene` 的插入子场景；不自动轮播、不由规则或 AI 自动公开。
- `COMPLETED` 后不得新增上屏，但仍可撤下或清除；已展示内容可进入安全回顾。

## 4. 流动星系

- 星色权威锁定后，本人恒星立即以稳定公开星号、稳定槽位和锁定色温加入公开星系，不再等待一个独立“星星集结阶段”才生成。
- 手机端本人恒星保持突出，并在其下显示本人星号；其他参与者恒星正常流动但不显示标签。
- 公开星系最多承载 300 颗真实参与者恒星，不用虚构参与者补位，也不得静默截断超额参与者。
- 客户端先读取权威快照，再处理幂等 `star upsert`；刷新、重连和事件重放不得生成重复恒星或移动既有稳定槽位。
- 色温由参与者选择；位置、尺寸和轻微差异可以由稳定服务端种子派生。

## 5. 页面结构与视觉

- 主界面以持续缓慢流动的大星系为主视觉，不再展示六阶段直线、`02 / 06` 等全局编号或常驻阶段说明。
- 删除普通状态下的“实时同步”、原始 `RUNNING` 文案以及没有决策价值的解释文字；异常、离线、暂停和完成状态仍清晰可见。
- 下半屏使用一个克制的液态玻璃操作坞承载当前场景的主要操作；不得把整个页面做成玻璃卡片墙。
- 操作坞必须在不支持透明/模糊时降级为高对比不透明面板；不得用持续动画 `blur`、`backdrop-filter` 或滤镜制造高耗电效果。
- “退出”放在原“实时同步”区域，每次退出都要求确认。
- `PROGRAM_SUPPORT` 中节目内容可在中央区域内部滚动，弹幕、礼物等主要操作保持在操作坞内并可被软键盘触达。
- 主要触控目标不小于 44×44 CSS 像素；安全区、横屏、短视口、125% 字号和 reduced-motion 均须保留完整功能。

## 6. 入场动效

正常首次入场分成两个只承载叙事、不提交业务事实的过场：

1. 有效核验完成、服务端确认首次新建身份并返回 `NEEDS_COLOR` 后，先等待页面处于稳定 `visible`，再用约 2.8 秒穿过星云、聚焦并找到一颗中性恒星；D-028 要求镜头与选色静态态共用一颗持久恒星，并固定在横向 `50%`、纵向 `42vh` 的统一视觉轴；
2. 用户选择色温的时间不设倒计时；
3. 服务端确认锁色且客户端取得权威星系快照后，用约 1.2 秒点亮本人恒星并拉远进入大星系。

首次寻星的四阶段固定为“建立/加速 → 连续穿越 → 减速/捕获 → 锁定/交接”。背景使用覆盖可用舞台的低 DOM SVG 径向速度线；目标恒星使用同心白核、中性光晕与默认 `5800K` 色温光晕。选色文案与控件在镜头中提前渲染但保持 `inert`、不可聚焦，最后一帧只解除交互隔离，不替换恒星节点，也不改变其中心、尺寸或颜色。正常完成由主动画 `animationend` 收束，定时器仅作有界兜底。

正常首次入场不提供跳过动画按钮。开始前页面暂不可见时等待到可见状态稳定后再播；镜头真正开始后若页面进入后台或被中断，则立即收束到静态权威终态，返回时不重播。`prefers-reduced-motion: reduce`、已完成相应步骤的返回用户、刷新、断线恢复、请求失败和等待超时也直接显示静态可操作终态。身份响应、权威快照、实时连接和允许动作不等待表现层完成。

首次叙事镜头只使用 Vue、CSS 与低 DOM SVG 的低成本 `transform`/`opacity`；Canvas 继续只承担权威星系，不新增 GSAP 运行依赖、大型动画库或重型 3D。怀士堂照片、线稿、几何轮廓以及其他建筑意象均不再进入手机端体验。动效完成回调不得作为激活、实时订阅、锁色、奖励、加入星系或完成活动的提交条件。

## 7. 反馈与草稿

- 成功提示显示约 3.5 秒后自动收回，同时由页面上的持久权威状态接替。
- 错误、离线、暂停和完成提示保持可见，直到状态改变或用户明确处理。
- 胶囊和公开内容草稿只保存在当前内存；完成、退出或会话重置时清空。弹幕草稿在离开 `PROGRAM_SUPPORT` 时额外清空。
- 网络断开时阻止写入，不在本地排队补写；恢复后先拉取权威快照。

## 8. 星光与未来抽奖边界

当前星光权重为：激活 20、首次实际胶囊提交 20、首次星星启动 20、首次送礼 10、首次规则通过弹幕 10、首次协同点亮 20。胶囊跳过奖励 0。

权重必须由服务端版本化，后续可以调整，但不得改写既有账本。当前不实现抽奖、中奖概率、兑奖或领奖核销；未来若引入概率，只能读取权威、版本化的星光事实。

## 9. v1 历史映射

| v1 基线 | D-025/v2 处置 |
|---|---|
| 六阶段直线与 `stage=1..6` | 由个人入场状态机与三个全场场景替代 |
| 身份激活阶段与胶囊阶段串在全场进度中 | 拆为每位参与者独立入场；晚到者完成后进入当前场景 |
| 约 0.9 秒、首帧可跳过的单段入场 | 由 D-027 替换为稳定可见后约 2.8 秒穿越式寻星 + 用户选色 + 约 1.2 秒拉远；正常首次不可跳过 |
| 星辰确认后进入轨道中心 | 锁色后立即加入持续流动的公开星系 |
| 普通状态显示“实时同步”、原始 `RUNNING` | 删除；只保留有决策价值的状态和异常 |
| 多块玻璃卡片和固定信息行 | 收敛为沉浸星系 + 单一底部操作坞 |
| 怀士堂或建筑轮廓 | 当前手机体验明确不使用 |

D-022、D-023、D-024、G5-01～G5-05 和既有自动化仍只用于解释 v1 历史。V2-08 已完成 D-027 之前的手机实现和桌面 Chrome 隔离临时 v2 栈 smoke；V2-09 又独立通过三浏览器三端闭环与 300 人协议负载；V2-10 的 30 分钟自动渲染 soak 已通过。既有 reduced-motion E2E 和只等待选色终态的检查器不曾证明 D-027；新鲜邀请、normal-motion、生产 Vue 页面与隔离 v2 smoke 后来关闭了时长/可见性缺口，但项目负责人真机观察进一步否决了首版视觉连续性，因此 D-027 的历史 `PASS` 不得扩张为视觉通过。D-028 已以正常首次 `2783ms`、隐藏→可见 `2717ms`、F6→F7 恒星中心/尺寸差 `0px`、CLS `0`、六帧目检、全量 37 文件/341 条测试、两项 typecheck、71 模块构建、三项目 v2 E2E 与现场预览 smoke 关闭自动连续性子门。自动门仍不能替代 vivo X300 对当前版本的新鲜邀请视觉签核、三端局域网与 OBS 实际合成人工验收，因此项目整体不得表述为已现场上线。
