# D-088：演职员目录与银河片尾

2026-09-10。负责人在 D-087 流程审查后同意开始修改。本轮先处理演职员数据同步、片尾视觉统一、一次播放收束与静态名单可读性。D-086 已认可的背景、星云、星点及运动保持；抽奖轮次、动力规则、线下串场不在本轮变更范围。

## 实现

- `performers` 成为按稳定节目 ID 保存的公开节目资料，后台待开始时可编辑，最多 240 字单行。手机节目单、当前节目、报幕和片尾共用后端目录，不再按节目名称匹配本地名单。空字符串表示有意留空；历史 JSON 未带字段时保留已有表演者。
- 正式节目来源仍是负责人提供的节目单。预设保留全部 21 项，18 个表演带公开表演者；串场/延期占位不混入演职字幕。片尾按当前启用的表演节目排序，改名、重新排序和移出目录均同步，不读取邀请名单。
- 片尾沿用 D-086 的黑色深空与银白银河，使用暖白字幕和细金色分隔线。8 秒致意后字幕按可读速度上行一轮，时长随实际文字高度变化，最后停留在“愿我们在更远的星海重逢”。统计放在终章次要位置，可跳过字幕。
- 新进入完成/预览事件才播放，刷新、断线恢复、隐藏中断和静态模式直接停留终章，不补演旧镜头。静态名单每页 6 项、手动翻页；极长文字有可操作滚动区域，不用无限动画才能读完。
- 保持现行主控契约：暂停会撤下排练终章，恢复不自动重播；重新点击“预览终章”才播放。完成状态和禁写立即生效，字幕结束不触发业务命令。

## 数据维护

新增 `0018_v2_program_performers.sql`，保留既有迁移文件内容与哈希。schema 17→18 只新增演职字段，并按已导入的 `event2026-01` 等稳定 ID 回填对应的公开节目资料；不改节目顺序、当前节目、热度、余额、礼物、弹幕、中奖记录、身份和 resetEpoch。新的 preset 直接携带同一资料。

维护入口：`pnpm db:v2:credits-upgrade --backup <全新备份路径> --confirm V2_SERVICES_STOPPED`。必须明确设置目标库与对应 manifest 环境变量并先停止本项目服务。入口先验证 schema 17、建立 SQLite 一致备份，再在事务中迁移、完整验证；失败回滚且保留备份，已有备份路径不可覆盖。旧 schema 12/14/15/16 的既有维护入口连到 schema 18。

本轮为本地修改和审片，**未执行服务器迁移/发布**。线上仍是 D-087 已发布的 D-086 前端与 schema 17。schema 18 不能用前端补丁单独上线；后续需匹配的后端、前端及数据库维护窗口，核对活动状态后只停止本项目，保留升级前代码与数据库配对用于回退。不得重置现有场次或影响其他站点。

- Chrome 与 Edge 各两项片尾用例全部通过（4/4）：新到达的完成事件立即播放，业务同时锁定；实际目录字幕一轮结束；刷新不重播；排练暂停/重开；三页静态名单均可见，包含最后一项。
- 完整生命周期复验有一轮在后端重连后直接呈现正确终章，失败于测试仍要求必有开场字幕。保留记录 `browser-lifecycle-reconnect-first.json`。完成状态与协同人数均正确；将全程恢复检查和新实时事件动效检查分开，遵守“不补演重连前镜头”的约定，不改业务去迎合该旧断言。该流程最终复验另记。
- 之后一次目录用例通过，全程用例在旧转场计时断言处失败：测得 15.692 秒超过 15.5 秒上限，但计时包含主控请求、截图和多次跨进程断言。改为在大屏浏览器中观察转场开始/结束属性，保留原 11.5–15.5 秒窗口，不放宽阈值、不修改银河或转场时长。首次记录 `browser-final-flow-first.json` 保留。
- 后续复验转场计时通过，但旧抽奖检查把“滚动中”和“已揭晓”两个时刻的读数混在一起，误报合法中奖星号提前出现。一次浏览器取样仍可能在主控请求返回后错过整个短动效窗口，最终在抽取前启动浏览器观察，同一帧记录滚动阶段、中奖历史和星号可见性。不改变抽奖规则或动画。记录 `browser-lifecycle-after-timing.json`、`browser-lifecycle-frame-window.json` 保留。
- 再次复验走完结束、核对了 1 人协同统计，在最后刷新时耗尽整条用例的 150 秒预算。全程预算调整为 210 秒以容纳三端截图与后端重启；单个转场时间窗口和界面等待断言保持严格。记录 `browser-lifecycle-time-budget.json` 保留。
- 同类临时节点检查还发现：弹幕按规则移出 DOM 后再取计算样式会得到空值。改为发送前观察实际弹幕，在节点仍连接时记录向左移动超过 80px 及透明样式，仍验证其真实运动与样式，不延长产品弹幕寿命。记录 `browser-lifecycle-barrage-node.json` 保留。
- 审片检查了 1920×1080、1280×720 的致意、字幕、定格与最后一页；无页面异常。18 个表演的审片实测字幕 137.35 秒，加 8 秒致意约 **2 分 25 秒**；时长由文字排版和可读移动速度决定，可随时跳过。独立审片暂停测试保持时刻不变，字幕完结后没有残余字幕动画。审片探针初次在动画切换边界读取失效动画对象，修正为先暂停再截图后通过，未修改产品播放规则。
- D-086 冻结清单中的 **16 个银河相关来源文件哈希全部保持**。没有改动已认可的银河素材、星云配色或渲染器。
