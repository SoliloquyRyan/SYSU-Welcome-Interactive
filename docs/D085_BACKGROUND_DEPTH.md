# D-085 远星、薄雾与暗尘遮挡

2026-09-09，负责人要求在现有四周背景上再加一点有层次的内容。本轮沿用 D-084 已收淡的配色、气体层和白边强度，通过疏密与遮挡增加纵深，中央银河和参与者星体继续作为主体。

- 最远处加入不均匀细星尘和四处小片远景星团，光点细小、中性、无标识、无光芒或动画，仅作为缓存背景材质。它们没有参与者身份、星位或人数语义。
- 叠入更远、更柔和的薄雾场，让近处暗尘埃吸收部分远光；同一片远景中的星点和薄雾因此有不同可见度。所有计算发生在已有背景缓存初始化阶段，没有新增每帧计算、材质缓存类别、纹理或依赖。
- 源码变化仅为 `stellar-sky.js` 与预览版本标签；主银河、参与者星色与尺度、相机、阶段、业务均保持。
