# 主持人动画对稿单 · D-110

本页仅作为本机离线对稿材料使用。服务器上的 `/welcomeparty/host-cues/` 已按 D-112 下线；从离线包解压后打开 `index.html`，点击播放，默认原速。按 25 项目录审阅；样片中的星号、投票、分数和获奖者均为合成演示，现场以主控已经发布的画面为准。D-109 录像保留为历史参考，不能代替现场 OBS 音频演练。

## 先约定四条口令

- **报幕背景**：主控切“报幕／主题背景”，OBS 收起上一段媒体。显示“2026迎新晚会”与“以星光作序，与未来相逢”，暂停送礼。
- **节目准备，走**：明确执行“执行选中项”或“返回节目”；OBS 操作员同步播放已核对素材。浏览目录不会自动切换现场。
- **揭晓，走**：主控核对候选、题目或获奖名单后确认发布；主持看到公开结果再宣布。
- **晚会结束**：主持宣布结束后，主控确认“结束晚会”。业务立即只读，大屏直接定格“感谢你的参与”；完整片尾只在后台和主持预览中查看。

## 正式入场与人员安排

- 所有 NFC 写入同一网址：`https://sysuzgxytj.top/welcomeparty/welcome`。
- 学生必须匹配正式名单的姓名和 8 位学号；同名按学号区分。已入场者再次进入即可恢复，无需退出登录。
- 工作人员使用“工作人员01”至“工作人员50”和各自 8 位随机口令，初始 100 动力，重复登录不重复发放。只分发本人那一条口令，不共享账号。
- 工作人员可发弹幕、礼物并触发动效，不计正式排行，不能投票、抢答，也没有后台权限。
- 工作口令清单和主控口令在本机受保护目录保管，不包含在 GitHub、网页、对稿动画或离线包内。

## D-110 半屏控台与 OBS 配合方式

控制网页放半屏，另半屏放 OBS。网页不含监视画面；通过节目、互动、颁奖、弹幕、管理五个页签处理现场事务，顶部与底部按钮固定。节目卡片只设为待执行，点击“执行选中项”才切换。

统一顺序：准备下一项 → 报幕／主题背景 → OBS 准备素材 → 按主持口令分别执行网页与 OBS → 节目或互动 → 收尾。互动投票或抢答未结束时，先关闭当前互动。不要把网页显示的素材提示视作 OBS 已经播放。

手机所有页面使用同一套竖版雾紫背景，入场仅显示本人星色及一次飞到屏幕中央的流星；大屏继续显示真实已入场星海。工作人员、游客可发弹幕和礼物；投票、抢答只对核验学生开放。

互动一不要点击旧版“开始抢答”来代替音频布置。正确口令是：**布置题目 → 桥接自动让 OBS 播放 `mix` → 自动倒数 10 秒 → 抢答开放 → 答错续播并继续抢 → 答对或主控关闭**。`hint`、`answer` 和普通节目音乐不会触发；音频自然结束也不自动关题。

## 重新开场

新版本发布不会清空数据。由主控在待开始、暂停或已结束时，点击底部“归档并重置本轮”，输入“重新开场”。成功后全员重新核验和锁色，校园奖需再次核对确认。失败时核对回执，不连续换口令重复点击；相同请求重试会返回原结果。旧轮次归档由负责人在受保护目录管理。D-110 本地验收期间不要执行该操作。
