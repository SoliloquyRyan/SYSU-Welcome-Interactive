## 2. 安全启动

1. 确认电脑与本次签核使用的实体手机在同一可信私网，关闭 VPN/代理，确认没有真实参与者数据。
2. 在 PowerShell 运行：

   ```powershell
   $env:DEMO_HOST = '192.168.x.x'
   pnpm preview:v2:field
   ```

3. 确认启动器拒绝公网、虚拟接口和 `0.0.0.0`，不自动改防火墙；手机扫码后地址栏令牌立即清除。
4. 正常动效首次镜头使用本次临时栈的新鲜邀请和无旧会话浏览器；同一身份的刷新/返回只能验证静态恢复。
5. 结束后按 `Ctrl+C` 或关闭预览浏览器，确认临时数据库和端口已清理，实际 `backend/.data/` 未变。
