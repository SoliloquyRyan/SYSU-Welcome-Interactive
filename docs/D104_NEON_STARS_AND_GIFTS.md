## 实现契约

- 共用 `ProgramStageBackground`：保留 D-103 的两张 WebP，霓虹、轨道、拱廊和水面反光用原创 SVG 图层区分，新增图片字节为 0。`PROGRAM_BACKGROUNDS` 只按 10 个稳定 ID 分组，改节目名不影响主题；未知 ID 使用通用主题。
- 大屏 120、手机 30 个装饰星点，与参与者星星和人数完全独立。前 6 个天空锚点供闪星及光波定位。城市音乐调制继续由 D-103 OBS 桥接负责。
- HOST 纯主题不显示通用标题、节目名条、礼物统计或礼物动画；SPEECH 独立标题与 AWARD 已发布内容保持。透明叠加进入 HOST 显示完整主题，返回有素材节目恢复透明；10 个缺画面节目自动显示对应主题。
- 标题字体：Smiley Sans 2.0.1 + Oxanium；正文和手机使用本地 Welcome Sans SC（Noto Sans SC 2.004 的重命名子集）。Noto 核心 UI 包与其余字符分片的 Unicode 范围互不重叠。字库覆盖范围内使用本站字体；Emoji、源字库外字符及下载失败使用可读兜底。
- 礼物效果：微光 800ms、信标 1400ms、星轨 1600ms、星舰 2400ms；小船 72px / 24px。CSS 只用变换和透明度驱动移动，天空层不接收指针，不关闭手机输入、选色或礼物弹层。
- 320ms 内同档同星色合并，保留数量但不延长已播效果。大屏并发 6、手机并发 2，等待最多 12 批，3 秒过期或溢出使用短暂静态星光汇总。连接内事件去重；暂停、隐藏、换节目、换环节、手机换页、减少动态、刷新与重连清理，不补播旧效果。
- `gift.sent.gift.displayColor` 可选、严格六位十六进制，只从服务器锁定星色取值；客户端命令不接受该字段。旧记录无颜色时显示中性星光。保留 `showStarship` 的旧事件兼容字段，新 UI 完全忽略该限制。不新增身份字段，不改账目、礼物定价、数量、幂等和 schema 21。
- 前后端作为同一版本交付。新前端可读旧礼物记录；旧前端的严格解析器不保证接受新字段，因此部署时必须同步发布并刷新三端。回退使用 D-103 的同版前后端，不需要数据库降级。

## 资产来源与归档

字体来自 [得意黑官方发布](https://github.com/atelier-anchor/smiley-sans/releases/tag/v2.0.1)、[Oxanium 官方仓库](https://github.com/sevmeyer/oxanium)、[Noto CJK 官方仓库](https://github.com/notofonts/noto-cjk)。许可证随站点放在 `frontend/public/licenses/`；`font-ranges.json` 固定来源版本、提交、哈希、覆盖范围与体积。无需运行时外部字体请求。

旧大型星舰组件、SVG、串行队列、时长与测试进入 `docs/archive/d103-large-starship/`，由 `manifest.json` 校验原路径和 SHA256。旧文件退出生产与预览运行引用；当前影院预览显示新小星舰。历史 D-100 / D-102 / D-103 文档和审阅产物保留。

字体可复建命令：

```powershell
python scripts/build-mobile-font.py --source output/typography-20260906/source/NotoSansSC-VF.ttf --license output/typography-20260906/source/OFL.txt
python scripts/build-font-ranges.py --source output/typography-20260906/source/NotoSansSC-VF.ttf --title-sources output/d104-font-sources
python scripts/build-mobile-font.py --check
python scripts/build-font-ranges.py --check
```

源字库与发布压缩包在忽略的 `output/` 保存，工程构建直接使用已生成的 WOFF2，不依赖 Python 或在线下载。

OBS `GetStats` 每 10 秒采样一次；平均渲染耗时和其 P95 反映 OBS 返回的平均渲染时间采样分布，不代表单帧延迟分布或 LED 端到端时延。音量事件抵达浏览器源与画面调制同时记录。真实混音线路、微信 iOS／Android 手机和场馆 LED 仍需现场验收。
