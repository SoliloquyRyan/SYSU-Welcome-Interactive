# D-062 银河连续镜头样片

这是可实际播放的独立美术预演，用于比较银河的体积、运动和转场节奏。D-063 已按负责人的认可把同一渲染核心接入正式 `/screen`；本页仍只记录独立样片，实际内测接入状态见 [`INTERNAL_TEST_20260906.md`](./INTERNAL_TEST_20260906.md)，不能作为场馆验收记录。抽奖美术与电影片尾继续在此后的设计工作中处理。

## 打开与重建

从仓库根目录执行：

```powershell
node scripts/build-galaxy-shot-preview.mjs
```

生成 `output/playwright/galaxy-shot-20260906/index.html`。用浏览器打开文件即可播放；页面包含脚本、程序化纹理生成器、既有本地中文字体及许可证，不依赖服务器、账号或网络素材。成片录屏与本机验证 JSON 位于同一目录，属于忽略的本地证据，重新构建不会生成新的录像或代替复验。

点击“播放样片”完整看一遍，再用“查看汇聚转场”复看开演前后。支持暂停、键盘操作时间轴、全屏、0/40/220/300 合成星位档位，以及开关节目底图。人数档位只在评审控制区出现；镜头中没有到场计数。关闭节目底图后，棋盘格用于观察图层透明度。

## 镜头与实现

| 时间 | 观看重点 | 具体变化 |
|---|---|---|
| 0–9 秒 | 星流与空间层次 | 固定星位映射到薄盘三维坐标，持续逆时针运动；相机沿小弧线靠近，星点、盘面尘埃和近处尘埃产生不同视差 |
| 9–约 14.6 秒 | 推进、汇聚与压缩 | 相机路径跨越触发时刻连续，星体按不同曲率和到达时序收缩；短拖影来自相邻时刻的投影位移，尺寸有界 |
| 约 14.2–17.4 秒 | 超新星与节目接管 | 高温核心后只出现一次不规则喷流与曝光，整幅 Canvas 连续变透明；最后一帧全部像素 alpha 为 0 |
| 17.4–19 秒 | 终态停留 | 观察下方独立示意层；正式节目内容仍由外部 OBS 提供 |

实现位于 [`frontend/preview/galaxy-shot/`](../frontend/preview/galaxy-shot/index.html)，构建入口为 [`scripts/build-galaxy-shot-preview.mjs`](../scripts/build-galaxy-shot-preview.mjs)。预演复用生产代码的确定性盘面分布、摄影式星色和转场包络，D-063 起与生产共用 `cinematic-galaxy-scene.js` 的三维投影、七层尘埃采样与相机路径；预演的合成星位生成和交互控制仍独立于生产。场景仍为一个可见 Canvas2D 与一个不进 DOM 的 WebGL2 缓冲，缓冲长边不超过 1280；没有增加运行时依赖。

420 颗无身份底星固定生成，合成参与者数严格按所选档位；改变人数不重排原有星位，零人也不会把装饰星计入人数。预演不读取后端、名单、身份、活动进度或节目运行库。画面中的节目底图专为评审透明接管而作，生产页面不导入它。

## 静态与失败路径

- 页面初次打开或普通刷新停在样片开头，须主动播放；它不承担正式运行状态恢复。
- 开启减少动态时直接到静态终态，JS 不循环绘制，且首次加载不分配 GPU 纹理。
- 页面隐藏时结束当前镜头，返回后不自动重播；后退缓存恢复也保留静态终态。
- WebGL2 不可用或上下文丢失时清空画布、停帧并说明原因。这是预演的静态降级；正式大屏现有 Canvas2D 动画回退未被修改。
- 离开页面取消帧请求、断开尺寸监听、清理事件和 GPU 对象。
