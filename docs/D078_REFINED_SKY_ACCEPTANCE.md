# D-078 背景远景精修

状态：2026-09-08，本地实现与审片，未发布服务器。负责人在 D-077 基础上要求背景更精美；本轮保留已认可构图、星色、手机个人星大小与云层聚散。

## 画面与实现

- 将原来平整的墨蓝渐层细化为低对比的远景云气、细碎星尘、银蓝微光和少量暖金过渡。远景与倾斜银河方向呼应，中心柔亮、四周柔暗，真实参与者星体继续处于更清楚的前景。
- 新增 `frontend/src/rendering/stellar-sky.js`，只生成确定性的 1024×1024 背景材质。远处光点属于材质细节，不是参与者、不可点击，也不进入到场人数统计。预览与正式页面共用此材质。
- WebGL2 与 Canvas2D 回退使用同一素材数据，手机按宽高比取中间区域；没有引入照片、外部图片请求或新的运行时依赖。
- 背景生成后缓存复用。原始 RGBA 缓冲 4 MiB；GPU 纹理随所属渲染器清理，Canvas 回退版本按需缓存。没有新增动画循环，也不逐帧重新计算背景图。原来的流动星云和星体继续使用 D-076 / D-077 轨迹与时钟。
- 业务、身份、人数、礼物扣费、节目状态、字体和 UI 布局保持；本轮不修改服务器、数据库或活动状态。
