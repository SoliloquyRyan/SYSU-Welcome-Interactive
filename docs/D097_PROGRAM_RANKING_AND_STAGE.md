# D-097：节目动力榜与统一舞台

2026-09-12，按负责人本轮要求实施。本地开发与隔离合成验证完成，未发布服务器或复位线上场次。

## 动力值与节目颁奖

节目颁奖固定为正式节目有效动力值前三名。主控可输入各节目的目标动力值，服务端保留原始送礼账目并记录调整差额；以后收到礼物仍继续累计。参与者账户余额、各种礼物数量保持真实账目。互动、颁奖及讲话不进入排名。

前三名由服务端生成，节目奖不再手填名单或新增奖项。影响第一至第三名或第三名入围边界的并列先提示主控调整，不能按目录顺序擅自决定获奖者。节目奖揭晓期间须先收起再调整分数。校园图鉴原有名单录入、确认及分页保持。

操作：在「舞台与颁奖」选择「节目颁奖」，查看「节目动力榜」。展开「调整节目动力值」，点击对应节目的「修改」，输入目标值后点「确定」。返回可取消；若编辑期间收到新礼物或其他主控已修改，重新打开最新数值后再提交。目标值为 0～1,000,000,000 的整数，修改历史通过服务端审计保留。首次前三名有并列时需完成调整，之后按「展示奖项 → 揭晓名单」向大屏公开结果。

原始节目送礼动力值与人工调整分开保存，当前有效值用于排名和节目展示；全场礼物数量与实际礼物总值仍来自真实送礼账目。新场次清除旧调整对当前分数的影响并保留历史调整记录。

## 视觉与转场

互动、颁奖和讲话继续使用无编号的独立分隔行，压缩上下留白。正式节目仍为 01～19，校园图鉴在手机节目单只显示标题。

节目背景与系统采用同一深黑、银蓝、细线视觉，手机、大屏、主持背景与颁奖协调。手机在实时进入节目阶段时播放一次超新星转场，完成后进入节目背景；刷新和重连不重复播放，跳过、打断、后台切换和减少动态最终都回到可操作的权威场景。动效不决定业务状态，也不阻塞节目操作。

手机转场 2.4 秒，从首帧可跳过；节目阶段卸载手机银河 Canvas。大屏沿用既有 12 秒开场，在后半段露出同一节目背景。通常前三名用三列荣誉台，第一名居中；任一标题超过 24 字或详情超过 100 字时改用三行，完整保留文本。
